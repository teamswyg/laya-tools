# Tiny hints: actual preparation69 and new roles70

The goal is to **cheaply suggest which evidence candidate an agent should inspect first**. This encoder-free claim-hint experiment is separate from training the Laya backbone. Sources and requirements still verify each suggestion; remaining candidates and fallback stay available when early suggestions are wrong. This does not authorize actions or prove correctness.

For “find Go files in nested directories,” several function captions may be available. The model proposes inspection order. Success means fewer **checks before finding an acceptable candidate** on identical requests. This remains a development proxy; actual LLM usage requires separate observation.
