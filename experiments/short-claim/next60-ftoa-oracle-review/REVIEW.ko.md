# ftoa 정답 검토

6개 Want의 정적 수학 근거에서 오류를 발견하지 못했습니다. 검토자는 Want·oracle·observer·후보 구현을 작성하지 않았습니다. 관측 결과 없는 nonblind 소스 검토이며, 빌드나 함수 실행을 통과했다는 뜻은 아닙니다.

1.125는 정확히9/8입니다. 소수 두 자리로 바꾸면112.5이며 짝수112를 선택해1.12가 됩니다. 1.375는137.5에서 짝수138을 선택해1.38이 됩니다. 실제 binary64의1.999는 자리올림 경계에서 충분히 떨어져2로 반올림됩니다. 작은 수1.25e-7도 아홉 자리에서0.000000125로 반올림됩니다. 음의0은 정책대로0, +Inf는 nonfinite 오류입니다. 이진 비트 예측은 실제 컴파일·관측한 비트값과 구분했습니다.

oracle은 비트에서 정확한 유리수를 만든 뒤 정수 나눗셈의 나머지와 짝홀수로 반올림합니다. 후보의 문자열 출력을 정답 생성에 쓰지 않습니다. 다만 입력 선택은 같은 Go compiler/runtime에 의존하므로 완전히 독립된 실행 증명은 아닙니다.

원본 FtoaWithDigits는 문자열만 반환합니다. 오류 채널의 unavailable을 nil 오류나 성공으로 바꾸면 안 됩니다. 새 후보의 typed 오류 정책과 원본 API는 별개입니다. `'f'`의 precision은 소수점 뒤 자리 수이며 유효 숫자 수가 아닙니다.

현재 실제 호출·qualified 추가는0이며 역할·라벨·가중치는 null입니다. 선택 컴파일 원천, 18개 관측용 외부 controller, CI·자원·Root의 사전 동결은 대기 중입니다. 향후 kill로 결과가 비어 있으면 호출 수는 unknown으로 보존해야 합니다. 원본·Want·seal을 바꾸지 않았으며 라이선스·학습·배포를 포괄 승인하지 않습니다.

정확한 핀·사례별 계산과 범위는 [검토 JSON](ORACLE-REVIEW.v1.json), 작업 기록은 [ledger](LEDGER.v1.json)에 있습니다.
