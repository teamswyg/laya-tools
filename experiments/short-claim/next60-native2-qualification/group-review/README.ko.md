# Native2 개발 학습 편입 준비

두 기존 draft 요청의 development_train 전용 편입안이다. 실제 정답·역할·가중치·qualified 수는 미할당이다. 봉인된 23행의 9 만족·14 불일치·unknown 0은 2개 요청·5개 후보의 유한 관찰이며 새 부모 23개가 아니다.

원래 76개 요청은 19개 그룹(학습 12·검증 4·보정 3)이다. 후속 실제 79개에는 UUID 두 요청(group 75)과 Ordinal 한 요청(group 76)이 학습 역할로 추가되어 21개 그룹이 있다. 이번 두 native 요청은 아직 포함되지 않았다. Catalog 등장과 실제 corpus 편입은 다르다.

draft20/native2 ID를 유지하며 pflag는 Cobra/pflag 연결 가족, mapstructure는 기존 mapstructure 가족에 속한다. source53의 다른 정책은 계보 참조이며 동일 계약이 아니다. 읽은 기존 메타데이터에 직접 source-family 충돌은 없지만 전역 고유성은 증명하지 않는다.

공유 source/helper/alias/fork/행동 template를 whole component 연결 근거로 삼는다. 메커니즘 이름·관찰기·표준 라이브러리·저자 이름만으로 합치지 않는다. 저자 흐름은 별도 다양성 한계다. 실제 연결이 기존 역할을 가로지르면 해당 fit 계획을 중단하고 분할·역할 이동·seed 탐색을 하지 않는다.

Root의 후속 typed qualification은 기존 사용자 승인 범위에서 source 근거·모델에 보이는 요구와 문장 충실성·고지와 사용 권리를 연결한다. 유한 match만으로 모든 입력의 성공을 주장하지 않는다. 미지원·panic·불완전 정보는 unknown이다. Flag.Changed나 오류 identity를 새 Want로 추가하지 않는다.

특징은 요청·후보 문장뿐이다. 기존 순서·정답·mask·null·역할과 음성/no_answer 분모를 보존한다. 새 허가 흐름이나 최종 readiness 판정이 아니다. [계약·핀](GROUP-PROJECTION-RECIPE.v1.json)과 [장부](LEDGER.v1.json)를 참조한다. 원 API·Go·모델·Features·Project·Fit·공유 변경/재실행은 0이다.
