# 다음 학습용 개발 자료: 요청 3개, 후보 라벨 8개

[English](README.en.md) · [Go reader 한글 사용법](../../../pkg/shortclaimdata/README.ko.md)

새로 실행한 실수 반올림 작업 하나를 앞서 검증한 네트워크·훅 조합 작업 두 개에 추가했습니다. 현재 개발 자료는 **서로 다른 요청 3개, 후보 8개(긍정 3·부정 5)**입니다. 입력 사례 15개와 후보 관측 41건은 정답을 검증한 증거이며, 추가 요청 수로 계산하지 않습니다. 원래의 두 줄은 바이트까지 동일하게 보존했습니다.

| 작업 | 확인한 범위 | 후보 수 | 학습용 전체 그룹 |
|---|---|---:|---:|
| 네트워크 설정 | IPv4 입력 5개 | 3 | 77 |
| 오류가 나는 훅 재시도 | 정수 훅 구성 4개 | 2 | 78 |
| 원래 실수를 직접 반올림 | 고정 실수 입력 6개 | 3 | 76 |

반올림 후보는 실제 실행과 [독립 검토](../next60-ftoa-actual-observation/semantic-review/REVIEW.ko.md)를 거쳤습니다. 개선 후보는 전부 만족하고, 원본·오류 후보에는 확인된 반례가 있어 후보별 가중치 1의 라벨을 부여했습니다. 원본의 오류 반환 채널 미확인 상태는 그대로 남습니다. 이 주장은 소수 2·9자리의 고정 입력에만 해당하며, 처음 기획한 0–18자리 API 전체의 검증은 완료하지 않았습니다.

이 자료는 기존 초안 20개 중 3개를 유한 범위에서 적격화한 것입니다. 새로운 초안 ID나 독립된 소스 계열이 생겼다는 뜻은 아닙니다. 반올림 작업은 기존 Ordinal 작업과 같은 humanize 전체 그룹 76에 연결합니다. 모두 개발 학습용이며, 새로운 소스의 일반화 점수나 보호 평가 결과를 제공하지 않습니다.

## Go에서 읽기

`data/train.jsonl`을 한 줄씩 `shortclaimdata.LoadDevelopmentRow`에 전달합니다. `Example.Input()`에는 모델에 줄 문장이 있고, `Supervision()`에는 후보 순서에 맞는 고정 배열 정답·가중치가 있습니다. `Metadata()`는 출처와 검토 범위입니다. 모델 특징에는 **요청 문장과 후보 문장만** 사용합니다. API 이름·ID·출처·그룹·정답·실행 결과를 특징에 섞지 않습니다.

[실제 검증 기록](INPUT-VALIDATION.v1.json)은 reader 3회와 기존 입력 검사 1회가 성공했으며, 마지막 줄의 문장·순서·평탄화된 ID가 [고정 입력](../next60-ftoa-actual-observation/INPUTS.v2.json)과 일치함을 기록합니다. [검증 코드](source/validate.go.txt)는 공개 자료의 모양과 대응 관계를 검사하며, 학습·점수 계산을 하지 않습니다. CI는 이전 두 줄의 재현과 이 세 줄의 검증을 함께 수행합니다.

기존 실제 79개 코퍼스와 모델은 그대로입니다. 합치면 82개 요청·23개 그룹이 될 수 있지만, 아직 합친 코퍼스를 투영·채점·학습하지 않았습니다. 이번 새 라운드에서 **30개, 60개**를 확보하는 체크포인트를 유지합니다. 현재 3개만으로 다시 학습하지 않습니다. 최종 보호 평가 목표도 주장하는 도메인마다 의미가 다른 요청 2,400개이며 아직 확보 완료가 아닙니다.

허깅페이스의 [3개 요청 고정 버전](https://huggingface.co/datasets/JooYoon/riidolaya-shortclaim-next60-development/tree/next60-3-finite-v1)은 게시 후 71개 파일을 다시 내려받았고, viewer 3행의 모든 필드도 원본과 일치했습니다. [게시 기록](../publication-proof-114/HF-PUBLICATION.v2.json)을 보세요. 기존 2개 요청 태그는 그대로 보존합니다. 게시 검증과 다음 자료 확보는 함께 진행하며 새 학습은 하지 않았습니다.

우리 문장·주석은 저장소의 Apache 2.0 조건을 따릅니다. 선택 원본의 [MIT 고지](notices/humanize-MIT.txt)는 별도로 보존하며, 이전 자료의 BSD·MIT 고지는 기존 고정 버전에 있습니다. 원본 코드 본체·바이너리·모델 파일·개인 입력·경로·추적 자료는 포함하지 않습니다. 전체 상위 라이브러리나 법적 계보를 일괄 재허가했다는 뜻도 아닙니다.
