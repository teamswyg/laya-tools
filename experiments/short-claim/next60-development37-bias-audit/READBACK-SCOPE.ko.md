저장 결과 재검산의 범위
======================

기존 Node 재계산 기록은 실제 저장 점수에서 기본 순위, 순열별 검사 횟수·1위 횟수·동점 쌍·동점 순위 횟수, 요청별 평균의 정수 합, 전체 행렬 해시를 재계산했습니다. BM25 점수 공식이나 실제 검증 비용을 독립적으로 검증한 것은 아닙니다.

해당 기록의 “모든 순열 지표” 표현은 전체 JSON 검증으로 읽으면 너무 넓습니다. fallback 요약 배열, 쌍 분모, 일부 기본 순서 요약, 평균 실수 필드, 기준선 대비 좋음·나쁨·동일 개수와 모든 스키마·상태 필드를 각각 대조하지는 않았습니다. 정확한 입력 SHA와 행렬 일치는 그 실행의 범위를 좁히지만, 일반적인 입력 검증이나 완전한 보고서 검증을 대신하지 않습니다. 기존 기록과 실제 결과는 보존합니다.

후속 Go 저장 결과 검사는 각 환경의 실제 점수로 전체 보고서를 다시 구성하고, 변경 가능한 파생값도 정확히 검사합니다. 원래 Mac 결과를 Linux 집계로 덮어쓰거나, 작은 점수 차이를 강제로 동점으로 만드는 방식은 사용하지 않습니다. 파일 쓰기·Sync를 수행한 옛 Node 기록만으로 일반적인 부모 디렉터리까지 포함한 내구성 거래를 증명했다고 주장하지도 않습니다.
