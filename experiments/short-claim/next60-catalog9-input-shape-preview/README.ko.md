# 다음 9개 요청의 입력 크기 검사

새 요청은 주석 값 복사, 범위 제한 카운터, 중복 할당 거부, 기본값 가림,
콜백 지연, 오류 원인 보존, 훅 오류 결합, 남은 필드 충돌, 태그 우선순위입니다.
이 폴더는 [고정된 10개 요청 제안](../next60-catalog10-literal-correction/CATALOG10.v2.json)
중 앞의 9개에 대해 Go 입력 검사를 실제로 9회 완료한 기록입니다.

요청과 후보 설명은 각각 32단어·512바이트 제한을 통과했습니다.
검사 코드는 입력의 크기와 정규화만 확인합니다. 원본 코드 실행, 기대값 비교,
모델 추론, 특징 추출, 점수 계산, 학습은 모두 0회입니다.
따라서 이 결과는 학습 자료 적격화나 기능 정확성의 증거가 아닙니다.
10번째 요청의 미확인 토큰 기록 기능은 계속 계측 보류 상태입니다.

- `input.go.txt`: Root가 작성한 입력 검사 코드. `.txt`는 저장소의 실행 패키지가 아닙니다.
- `INPUT-GATE.actual.v1.json`: 실제 완료 횟수와 요청별 크기. 개인 작업 입력은 포함하지 않습니다.

현재 학습 자료는 [7개 요청·20라벨](../next60-development-seven/README.ko.md)입니다.
새 요청 수에는 이 입력 검사만 통과한 9개를 더하지 않습니다.
