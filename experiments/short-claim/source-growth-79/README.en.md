This is a source-selection and acquisition proposal. No actual parents, captions, truth labels, roles or weights have been created or assigned. See [SOURCE-TARGETS.v1.json](SOURCE-TARGETS.v1.json).

## Small observations, visible conditions

Requests contain 20–25 ASCII whitespace words and 141–165 bytes. Original Normalize was not called. Propose three initial candidates per request, with an upper bound of eight. Model input remains **request + caption only**. Code, IDs, source metadata, truth, observed answers, roles and license metadata do not become hidden features. A condition absent from the caption does not become learnable merely by increasing the number of rows.

Later finite contracts should preserve return values, errors, panic, nil/empty, partial output and before/after state separately. UUID's 32-byte Parse writes the calculated byte before checking the hex-pair success flag; its 36-byte path checks success first. Do not invent equal partial arrays or zero at the failed slot. Scan's early return preserves its receiver despite the empty-input comment referring to a null UUID. inventory53's authored request to change that behavior is not existing truth.

Proposed observation bounds are eight fixtures per goal, 512 input bytes, eight list items, 256 bytes of memory-file data and one worker with CPU1, a 256MiB soft heap, 60 seconds and 1MiB output. Fix an actual API-call budget after reading adapter and constructor paths. At most96 fixture slots would not be96 independent problems or96 API calls. These bounds do not authorize execution.

Separate source satisfaction from coverage in model-visible captions, then use the existing process to freeze independent finite expectations and observation scope. Consider no-answer only when all supplied candidates are sufficiently shown unsatisfying; keep missing or ambiguous conditions unknown. Original76 truth, masks, roles and failed models remain unchanged. Future fitting and default activation depend on separate results. **Twelve development drafts cannot replace the untouched final target of at least2,400 requests per domain.**
