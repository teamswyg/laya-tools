# 고정 모델 비교에 쓰는 한정 평가 기준

이 파일은 요청75 v4와 독립 검토의 소스 충족 제안을 이번 개발 진단용 평가 기준으로 고정한 이유를 설명한다. 원래 제안 파일의 null 정답·역할·가중치·그룹은 수정하지 않았다. 학습 자료나 최종 골든셋에 편입하는 승인도 아니다.

`riido-caption-inference76-root-truth.v1.json`은 22,615 B이고 SHA-256은 `1cec5c108d09e78f3dd6a3465538bf9589df6d2f981edb4b12b736321aa648d6`이다. 요청, 후보 코드, 후보 순서, 한정된 소스 판독 근거를 고정한다. 직접 선택 API와 요청에 명시한 입력 범위에서 datasize의 후보0, query의 후보1, shlex의 후보2가 해당 조건을 충족한다. 나머지6개는 직접 반환 형태나 정책이 요청과 다르다. 보이지 않는 어댑터나 구현을 가정하지 않는다.

A의 기존 설명과 B의 행동 설명은 같은 코드에 대응한다. 두 arm에서 같은9개 후보와 같은 평가 기준을 유지하고 정보가 부족한 A 후보를 삭제하지 않는다. 모델이 보는 특징은 영어 요청과 선택한 설명뿐이다. 정답, 소스, ID, 근거, 후보 위치는 특징에 넣지 않는다.

두 고정 모델의 순서 차이를 탐색하는 데만 사용한다. 실제 함수의 모든 입력에서 성립하는 보편 정답, 인간만 작성한 독립 자료, 미관측 저장소 성능 또는 보호된2,400개 평가를 뜻하지 않는다. 작성자는 이전 결과와 소스 검토에 노출된 AI-assisted nonblind 검토자다. 3개 논리 부모의 번역·설명 버전·모델별 점수를 새로운 독립 요청으로 세지 않는다.

루트는3×3 후보 수, boolean 충족 여부와 acceptable indices `[0] / [1] / [2]`의 일치, `qualification`, 학습·운영·final 승인 false와 참조 SHA를 확인했다. 최초 projection 뒤 `qualification:false`를 추가하고 최종 해시를 봉인했다. 이 준비에서 모델 Decode·특징·점수·학습·원 API 실행은0회다. 실제 비교는 실행 기록이 생긴 뒤 따로 보고한다.
