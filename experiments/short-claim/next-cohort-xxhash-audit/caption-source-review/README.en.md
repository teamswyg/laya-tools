# Match captions to code before admitting training data

[한국어](README.ko.md) · [Complete review, pins and proposed captions](REVIEW.public.v1.json)

A small hint model sees only request/candidate text. Correct code paired with a
summary that omits essential checks can produce misleading supervision. We compared
the existing xxhash captions with their pinned implementations and prepared a
separate text revision. This record does not admit training data or train a model.

xxhash remains one parent request. Fifteen fixed inputs × five implementations
are the existing75 trials, not75 independent examples. Direct/reconstruct matched
15/15 contract cases; legacy7/15, roundtrip10/15 and digest7/15. These are finite
behavior observations, not universal correctness or assigned learning labels.

A separate source-only reviewer reread all five corrected captions and found no
material mismatch within the pinned15-fixture scope. This is a nonblind, exposed,
post-hoc development proposal. Original frozen requests/captions, observations and
failed model preview remain unchanged. ASCII word/512-byte prechecks are provisional;
no actual product validation, worker replay or model scoring occurred during this
preparation.

The old authored atomic-commit body and final qualified Bitset implementation were
also compared within three specified regions. Bitset's1870B final body matches its
frozen plan/manifest pin. Similar validate-then-commit structure did not establish
a copied helper/template correspondence in those bodies. It does not prove absence
of all external ancestry, helpers or forks.

Remaining gates are source relationships, purpose-specific training/publication
rights and complete-component development roles. No roles, learning labels or
weights are assigned; fitting, default activation and protected-final reads remain
zero. Unverified candidates cannot become negatives. An actual cross-role source
connection stops affected fitting without moving old roles.

If admitted later, this exposed parent remains development-only, never heldout or
final. Observe materially different independent parents and compare BM25 against
verified work/check counts and total task cost. Faster scoring or memorizing this
one example does not establish semantic quality or LLM savings. Existing37 data
and independent2400 final planning remain separate.
