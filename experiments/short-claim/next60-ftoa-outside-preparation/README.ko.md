# 반올림 관측을 위한 제어기 준비

[English](README.en.md)

작은 주장 모델에 쓸 설명을 만들기 전에 실제 코드 동작을 확인하려는 준비입니다. 반올림 요청 1개·입력 6개·후보 3개로 **관측 18회와 별도 계산 6회**를 계획했습니다. 실제 원본·계산 함수·모델 호출은 아직 **0회**이며 새 적격 요청·라벨·학습도 없습니다.

Root는 작성자의 봉인본을 유지하고 별도 디렉터리의 소스 6개를 정리해 합성 검사를 실행했습니다. **race 테스트 28개 통과·1개 건너뜀**, vet·형식 검사도 통과했습니다. 건너뛴 것은 실제 worker 바이너리 검사입니다. [검사 기록](root-tested/ROOT-FAKE-TEST-RESULT.v1.json)을 확인하세요.

검사 명령의 부모 프로세스 최고 RSS는 **121,012,224바이트**입니다. 원본 worker·모델·GPU 메모리 측정값이 아닙니다. 작성 시점의 [소스 준비 상태](author/FACTS.v1.json)와 이후 Root 검사 기록은 서로 다른 시점·작업자의 사실로 보존합니다. 원본 한 파일과 작성자 봉인은 수정하지 않았습니다.

다음 실행에는 정확한 컴파일 원천·의존성과 고지·자원·제어 경계, 실제 바이너리 연결 및 새 봉인이 필요합니다. PR111 CI와 예정 HF 개발 데이터 공개는 대기 중입니다. 현재 학습 자료는 기존 [적격 요청 2개·후보 라벨 5개](../next60-native2-qualification/README.ko.md)이며, 30/60 학습 체크포인트와 주장 도메인별 보호 평가 2,400개 목표를 유지합니다.
