# Independent review of the first next60 contracts

The first 20 drafts are useful source-grounded designs, but **none is ready for original execution, labels or training**. I completed a read-only review of all 20 requests, 96 finite vectors and 59 candidate descriptions, verified 18 exact links to Source53, and checked 38 public-original/source-metadata byte pins. Original execution, candidate building, scientific/model calls, new labels and external writes in this review are all **0**. Reading a source contract is not running an experiment.

The strongest competing explanation is that this batch mostly expands an existing inventory and recognizable API vocabulary. It may teach matching names or project-authored descriptions rather than improve inexpensive claim prioritization. The two native contracts are newly authored requests, but neither adds a new source family. More vectors improve discrimination within a contract; they do not establish more independent requests or generalization. The current zero-qualified status is therefore appropriate.

The immutable input is `DRAFT-CONTRACTS.v1.json`, 209,341 bytes, SHA-256 `c7bbf7bcc7912300fabdd6e671b0922df295299f00e5e7201df1ab5e824a2a9b`. Its public-final-pins manifest is 3,245 bytes, SHA-256 `0c3df33513224e0bcafa4687c49a255167eca4c536061f6ba93677c83c6db070`. The author's initial message estimated a different draft length; the author corrected that estimate and independent readback agrees with 209,341. This review leaves that sealed preparation unchanged. `SOURCE-READ-RECEIPT.v1.json`, `METADATA-QA.v1.json` and `OLD79-COMPARISON.v1.json` provide compact evidence without copying original source bodies or private scientific output.

## First two native contracts: smallest faithful observation

For IPNet, source at [ipnet.go:17](https://github.com/spf13/pflag/blob/c966cfef47379dcb01e7929504d66d94b540945b/ipnet.go#L17) trims whitespace, delegates parsing to net.ParseCIDR and writes state only after success. Initialize each vector with owned IP `[192,0,2,0]` and mask `[255,255,255,0]`. The three success Wants are respectively IP/mask `[192,0,2,0]/[255,255,255,0]`, `[203,0,113,5]/[255,255,255,255]`, and `[0,0,0,0]/[0,0,0,0]`; the invalid /33 and missing-prefix inputs return nonnil errors and preserve the initial bytes. These are static literal expectations, not observed outputs.

A future observer can register the three exported IPNet/IP/IPMask values on fresh explicit FlagSets and call each stored Flag.Value.Set. Capture tagged original state types, owned byte snapshots, returned errors and panic separately. Do not synthesize a network result for IP or IPMask. Direct Value.Set does not run FlagSet.Set's Changed bookkeeping or its error wrapping, so the chosen route must be explicit. Registration can call String implicitly; every constructor/helper/formatting call must be accounted for apart from the 15 candidate-vector observations. A String/GetIPNet readback would add original/helper calls and potentially reparse the input, so prefer literal byte snapshots. IPv6, error-message text and broad parser correctness remain excluded. A later nonzero host /0 or /31 vector would strengthen masking discrimination but would be a new frozen version, not another request.

For alternative hooks, [decode_hooks.go:140](https://github.com/go-viper/mapstructure/blob/52aa5c6dc1d27226460807054ca2107b2d54fb2d/decode_hooks.go#L140) reuses original from/to reflect values, stops at the first nil error and concatenates failure messages. Use a concrete integer 4, a valid integer destination reflect.Value, a fixed supported hook signature and fresh immutable E1/E2 causes. Compare OrCompose and Compose on the same literal hooks without changing their behavior. Capture callback ordinal, seen type/value, result dynamic type/value, error nil marker/string and panic. Capture nil-result success distinctly from all-fail null result and empty-list nonnil error. Message equality does not prove errors.Is identity; do not add wrapped-cause claims to the native concatenation contract. Constructors, cached hook normalization and DecodeHookExec are separate from eight candidate-vector observations.

The present review permits no build or execution. The 15+8 observation outline is a conditional design, not an actual original-call count or a complete whole-process call count. Current contract minimum review lists are not complete compilation closures. Source81/82 archives may reduce acquisition work, but the new observer, exact package selection, dependencies, build tags, toolchain/notices, static init effects and resource plan still need their own frozen binding. A separately sealed implementation can be reviewed without changing this draft history.

## Deduplication, grouping and rights

Public saved membership76 plus the public qualified append3 were read to compare all 79 request records. Exact request-text matches with the 20 drafts were 0. Text inequality is not proof of semantic independence. The contracts differ concretely from old integer/slice/event/UUID/ordinal/SemVer/glob behaviors, but shared mechanisms remain explicit: byte budget→quota-total, map snapshot→owned-snapshot, rollback→atomic-commit, cleanup→cancellation-lifecycle, hook routing→transform-order/error-identity, quotes→quoted-delimiters. The reviewed distinction is contract scope, not a new origin or unseen-family certificate. Source53's 18 IDs remain existing logical requests. Rephrasing, changing literal inputs, adding mutant variants or removing the correct candidate cannot add request counts.

Cobra+pflag stay one connected family; pflag and mapstructure are exposed through Source81, and humanize through the old79 training append. No member of this reviewed batch becomes protected final data. Record actual borrowed helpers, copied code, aliases/forks and shared postprocessors as graph edges before assigning roles. Common standard-library imports or Go Authors attribution alone do not merge all families; Go imports and copied-source lineage are different evidence. If a future concrete edge crosses old roles, stop the affected fit plan and preserve evidence rather than silently split or reassign it.

All seven root license copies were byte-verified, but the draft's release/training-clearance fields remain false. Local evidence records BSD-3-Clause pflag, MIT mapstructure/humanize, Apache-2.0 afero/Cobra/INI and MPL-2.0 retryablehttp. This is an evidence/status review, not blanket legal clearance. pflag's copied Go flag source, mapstructure's copied Go notices, INI's JSON-origin signal, afero's Go Authors/multiple holders and humanize number.go's separate origin each need selected-file provenance. The prior small Ordinal slice excluded number.go; it does not clear a future whole humanize build. No NOTICE in a complete upstream tree does not clear ancestor/dependency notices. Current MPL rights hold is an unresolved project policy; it is not a finding that MPL categorically forbids these experiments.

B is the best next preparation, followed by a small C subset. Freeze truth from observations and independently reviewed Wants first; freeze faithful short captions, order, limits, group roles and weights separately. A successful source comparison is not an LLM-success result. Measure hint utility against the same lexical and no-hint baselines only under a separate experiment, including total verifier/agent work, latency and peak OS RSS; no savings claim comes from this review. Keep the first 30/60-qualified goals separate from the current fixed79 loader and retain the protected final target of at least 2400 genuinely separate semantic requests per domain.
