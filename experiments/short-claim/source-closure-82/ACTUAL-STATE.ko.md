# Source82: 실행 전 원문 준비

Source81의 네 행동 목표를 나중에 원본 Go 코드로 확인할 수 있도록 누락된 원문을 취득했습니다. 이 단계에서 원 함수나 모델을 실행하지 않았습니다. 소스를 내려받았다는 사실과 컴파일·동작 검증·학습 준비 완료는 각각 별도입니다.

새 HTTP 요청은 **46회, 모두 성공, 재시도 0회**입니다. 원문 44개와 메타데이터 2개를 받았고, 과거 보존본 13개를 바이트 그대로 연결했습니다. 보존된 원천·모듈·라이선스는 총 **57파일·332,806바이트**입니다. Go 1.27.1 조건으로 선택할 런타임 파일 48개를 소스에서 제안했지만, 아직 컴파일러가 실제 선택한 파일이나 링크 결과는 아닙니다.

역사 문서의 실패 순서는 [별도 정정문](CHRONOLOGY-CLARIFICATION.v1.ko.md)을 함께 읽어 주세요. 정확한 순서는 **HTTP 46회 성공 → 기록 작성 도구 컴파일 실패 2회 → 세 번째 컴파일·기록 성공**입니다. 실패한 도구 자체의 추가 HTTP·원 API·생성 결과는 0입니다. 원래 72파일 stage를 고치지 않고 정정문과 [근거 장부](CHRONOLOGY-CLARIFICATION-RECEIPT.v1.json)를 추가했습니다.

## 확인할 자료

- [취득 계획](ACQUISITION-PLAN-82.v1.json)과 [실제 결과](ACQUISITION-RESULT-82.v1.json): 먼저 정한 한도와 전체 요청 결과
- [소스 검토](SOURCE-REVIEW-82.v1.json): 빌드 조건·import·복사 코드·관찰 범위
- [원문 고지](NOTICE-82.md): mapstructure MIT, pflag BSD, 복사된 Go 코드의 BSD 고지
- [공개 stage 인계서](PUBLIC-STAGE-HANDOFF-82.v1.json)와 [체크섬](SHA256SUMS): 변경하지 않은 과거 보존본의 목록

과거 인계서의 `external_publication: 0` 등은 준비 당시의 기록입니다. 이 문서와 정정문은 그 stage 이후의 별도 추가물이며 과거 체크섬 목록의 분모에 소급해 넣지 않습니다. 전체 source-first README도 원래 바이트를 보존합니다.

프로젝트의 Apache 라이선스로 원천 MIT/BSD 고지를 덮어쓰지 않습니다. mapstructure 안의 Go Authors 2022 고지와 pflag의 Go Authors 고지를 포함해 원문 헤더와 라이선스 전문을 보존했습니다. 특정 복사 코드의 원래 Go revision을 찾지 못한 경우도 기록에 남았습니다. 새 사용자 요청·정답·역할·가중치·학습은 0이며, 보호된 최종 2,400개 검증을 충족한 자료로 세지 않습니다.
