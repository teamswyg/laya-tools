# 다섯 작업의 실제 관측과 유한 검증

[English](README.en.md)

nil decoder 설정, 오류 출력의 실패 전달, required annotation 검증, 취소된 context의 사전 검사, 큰 정수의 정밀도 표시에 대해 서로 다른 요청 5개를 검사했습니다. 입력 23개와 예상 동작을 먼저 고정하고 후보 3개씩 실행해 [69관측](OBSERVATIONS.v1.json)을 저장했습니다. 요청 수·입력 수·후보 수·관측 수를 서로 대신 세지 않습니다.

| 단계 | 실제 결과 |
|---|---|
| 최초 원본 실행 | Start 1회·Wait 1회·종료 코드 0·69건 완료 |
| 후보 반환 / panic | 67 / 2; panic도 관측으로 보존 |
| 명시적으로 호출한 오류 메서드 | 23회 반환·panic 0; 원본 내부·초기화 호출은 미계측 null |
| 저장 결과 비교 | 69행: 만족 42·불만족 21·판단 불가 6 |
| 세부 조건 비교 | 228개: 참 185·거짓 32·판단 불가 11 |
| 검사 worker 비용 | 최대 OS RSS 24,641,536바이트(23.5 MiB), 시작·대기 약 1.20초 |

이 시간과 메모리는 로컬 Go 검사 프로그램의 시작·기록·동기화를 포함합니다. 모델 추론·GPU 메모리·Go heap·Codex 토큰 절감 측정이 아닙니다. 원본 후보를 재실행하지 않았습니다.

참조 후보 5개는 고정한 모든 조건이 알려진 참입니다. 후보 9개에는 알려진 반례가 있습니다. **오류 writer 원본 후보는 반환값을 관측할 수 없어 판단 불가로 남기고 학습에서 제외했습니다.** BigBytes 원본에는 알려진 문자열 반례와 별도의 판단 불가 입력이 함께 있습니다. 불만족으로 채택할 때도 그 미상 조건을 지우지 않았습니다. [독립 비눈가림 비교](semantic-review/README.ko.md)와 [Root의 별도 적격 근거](root/ROOT-QUALIFICATION.v2.json)를 구분해서 읽으세요.

새 5개 요청은 긍정 5개·부정 9개인 14라벨을 추가합니다. 기존 16개와 합치면 적격 요청 21개·61라벨입니다. 전체 근거는 입력 103개·원관측 305개입니다. 학습에서 제외한 원본 후보의 4관측을 빼면 선택한 후보의 관측은 301개입니다. [새 JSONL 생성·실제 reader 검증](../next60-development-twentyone/README.ko.md)도 완료했습니다. 적격화만으로 새 학습을 실행했다고 주장하지 않습니다.

제외된 원본 후보 다음의 참조 후보는 선택 배열의 인덱스 0이 됩니다. 따라서 두 번째 후보만 고르는 산술 기준은 **18/21≈85.7%**입니다. 모든 후보를 부정이라 부르는 기준은 **40/61≈65.6%**이며 분모가 다릅니다. 둘 다 모델 성능 측정이 아닙니다. 원천 연결 그룹 76·77·78을 재사용하므로 새로운 원천 일반화 근거도 아닙니다. 새 corpus 학습은 적격 요청 30개 전에는 시작하지 않으며 60개 점검·도메인별 보호 평가 2,400개·효용 5% 기준을 유지합니다.

첫 수집기 호출은 고정 파일 끝의 LF 두 개를 LF 한 개로 예상한 검사에서 멈췄습니다. [당시 실패 기록](PRESTART-FAILED.v1.json)의 Start/Wait은 둘 다 0이고 worker 출력은 없습니다. 원본 입력과 Wanted 바이트를 유지하고 소유한 파일 검사 코드만 고쳤습니다. 그 앞의 함수/타입 이름 충돌도 원본 실행 전 준비 단계의 컴파일 오류였습니다. 실패 이력을 지우거나 정답을 바꾸지 않았습니다.

CI의 `five` 단계는 소유 소스의 합성 제어 검사와 **이미 저장한** 결과의 재비교입니다. 실제 69관측 worker나 모델을 시작하지 않습니다. 전 저장소 CI의 기존 native Laya 단계는 별도입니다. [수집기 결과](OUTSIDE-RESULT.v2.json)의 자식 종료·출력 일치·사후 핀 확인과 유한 정답 비교는 서로 다른 검증입니다.

[소스 선택 초안](SOURCE-SELECTION.v1.json)은 실행 전 상태 그대로 보존한 기록입니다. 이후의 실제 검토는 `root/ROOT-SOURCE.frozen.v2.json`과 `ROOT-COMPILER.frozen.v2.json`에 있습니다. 소유 코드만 `source/`에 보존했고 upstream 본문·실행 파일·원시 journal·사설 경로는 게시하지 않습니다. 원본/파생 Cobra, 정확한 pflag 1.0.9, mapstructure와 humanize의 전문 고지는 `notices/`에 있습니다. 자체 자료는 저장소 Apache-2.0, upstream 고지는 원래 라이선스를 유지합니다. 실행 경로가 포함된 비공개 plan은 게시하지 않으므로 같은 경로·바이너리의 무변경 재현을 주장하지 않습니다.
