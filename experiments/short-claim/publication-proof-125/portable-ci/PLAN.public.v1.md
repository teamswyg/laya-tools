# Portable frozen-report checker preparation

Source-only replacement for the existing authored public_frozen_test.go. Production baseline scoring, exact stable ties, the frozen Mac results and other quality gates are unchanged. Root alone materializes/formats/tests/applies this source and runs CI.

The same 219 cases / 876 ranking records, 33 parents / 96 selected candidates and 186 permutations remain required. Parent IDs, candidate IDs, frozen labels, style, scope, counts, fallback reasons and case permutations are exact. The checker independently validates each actual descending score order, display-stable exact ties, zero inactive slots, exact == tied-pair flags, selected mapping and first-positive visit. It independently recomputes all actual primary/permuted totals and reductions from the unmodified actual orders and frozen labels.

Each score retains abs(actual-frozen) <= 1e-12*max(1,abs(frozen)). Frozen pairs with gap strictly greater than the sum of their two bounds retain their relative order. Overlap-pair order and exact-tie differences are allowed only when the actual report is otherwise independently valid; they and any first-positive/aggregate differences are retained. Scores are never replaced with frozen values. No production tolerance-tie rule or blanket ranking exemption is introduced.

The existing test name remains. Frozen report bytes/SHA are pinned in public source. After Run succeeds, RIIDOLAYA_BIAS_ACTUAL, when nonempty, names a fresh full actual report. Its bounded sidecar is that pathname plus .diff.json. The full unmodified report is O_EXCL-written 0600 and file/parent-synced before comparison. The sidecar records every changed rank, both score/order/tie/visit versions, overlap flags, original frozen/actual aggregates and independently recalculated actual totals. Failure preserves the already written actual file; existing/partial artifacts are not removed, overwritten or retried. Full report plus sidecar must total <=1 MiB. Empty env prints the bounded diff; Root workflow decides artifact requirements.

Fake controls contain no saved data or production ranker/Reader calls. They require acceptance of a valid near-tie order/tie/visit/aggregate change and rejection of robust inversion, corrupted ties/stable ordering, selected mapping, visits, aggregates/reduction, styles, labels, permutations, fallback, counts, inactive slots and nonfinite scores. A synthetic persistence control checks that a failed report remains intact and cannot be overwritten.

Only public_frozen_test.go.txt and this document are public-copy candidates. Private pins and handoff/manifests contain private paths and are excluded. Source contains environment variable names and a public content hash only, no private absolute paths. Frozen results are not copied or overwritten. This preparation executes no Go, Reader, original/API/model/Fit, network or Git operation; labels and new qualification remain zero. Source controls are unexecuted; Root compilation and independent source review remain necessary.
