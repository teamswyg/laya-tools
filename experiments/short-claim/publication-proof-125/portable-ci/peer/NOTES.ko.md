# CI125 portable checker 소스 검토

새 검사 구현에서 구체적인 blocker나 필수 소스 수정은 발견하지 못했습니다. 이 결론은 소스에 한정되며 컴파일·테스트·CI 실행 성공을 뜻하지 않습니다.

기존 점수 함수, 정확한 동률 규칙, Mac 결과는 유지됩니다. 실제 점수로 모든 순서·정확한 동률·매핑·첫 양성 방문 수·집계를 다시 확인하고, 기존 점수 허용오차 및 명확히 벌어진 pair의 순서를 별도로 검사합니다. 작은 간격 pair의 플랫폼 차이도 원점수와 실제 동률·순서·방문·집계 양쪽을 보존합니다. 전체 필드를 지워 비교에서 제외하는 방식은 없습니다.

CI는 RIIDOLAYA_BIAS_ACTUAL을 명시하고 부모 디렉터리를 먼저 만들어야 합니다. 전체 actual.json과 actual.json.diff.json은 각512KiB, 합계1MiB 이내에서 새 파일로만 저장됩니다. 테스트 staging 정리 범위 밖 runner 임시 디렉터리를 사용하고, 실패 시에도 두 경로를 업로드하는 wiring을 적용해야 합니다. artifact 저장 실패·검사 실패는 CI 실패로 남아야 합니다.

검토자는 이전 bias 소스 준비와 플랫폼 비교 계약 제안의 저자이며 현재 검사 구현의 저자는 아닙니다. 비눈가림 소스 검토로서 자신의 이전 구현을 독립 검증했다고 주장하지 않습니다. Go·Reader·Baselines·원본 API·모델·학습·네트워크 실행과 정답·역할·적격 결정은 모두0입니다. Private pin 파일은 공개 제외입니다.
