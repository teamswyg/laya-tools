[계약22개](TASKS.proposed.v2.json)는 봉인 당시 제안이며 Want/Got·라벨·수집 자격은 확정하지 않았습니다. 기존13개는 후보 문구·순서가 null이고 추가9개 문구27개는 미래 구현의 주장입니다. [위치·문체 균형안](PRE-OBSERVATION-BALANCE.proposed.v2.json)도 관측 전 계획입니다. 참고 후보를 이름 때문에 양성으로 정하지 않고, 여러 후보가 실제 만족할 가능성도 유지합니다. 현재30행 변환기의 단일 양성 규칙을 새 자료에 조용히 적용하지 않습니다.

[문구 검사](EXACT-TEXT-CHECK.v1.json)에서 새22 요청·추가27 후보 문구는 기존79·현재30 및 서로 간 정확/정규화 문구 중복0입니다. 하지만 [의미 검토](SEMANTIC-REVIEW.v1.json)는 정수 범위·ties-even·상태 보존·복사 시점 등 공유 계약을 남겼습니다. 기존79 안에는 요청 중복18쌍과 후보 문구 중복257쌍이 있으며 쌍 수는 중복 요청 수가 아닙니다. 기존79+현재30=109도 행 수 합계입니다. 보호2,400개·정답·모델 점수·특징·Fit은 이 검토에서 해석하지 않았습니다.

원천 목록은 Bitset의 누락 생성 파일을 Git blob/SHA로 확인하고, GJSON의 Match1.1.1·Pretty1.2.0 정확한 소스·MIT 고지를 확보했습니다. Go1.27.1의 오프라인 go list -deps 두 번은 성공했으며 선택 runtime Go는8파일입니다. Bitset은 표준 패키지72개, GJSON은73개이며 **표준 합집합73개**입니다. 이는 컴파일·초기화·ABI·API 실행 검증이 아닙니다. 옛 인계의78 표기는 원 봉인을 유지하고 추가 정정합니다. 봉인 당시 계약의 의존성 미확보 메모는 당시 상태이고, 이후 준비로 실행 자격이 자동 생기지 않습니다.

Bitset·Decimal·GJSON은 학습, xxHash·Chi는 검증, Uint256은 보정의 조건부 후보입니다. 실제 whole-family 역할·숫자 그룹은 아직 배정하지 않았습니다. 공통 Go 저작권이나 stdlib import만으로 합치지는 않지만 공유 helper·포팅 계보는 확인해야 합니다. [Root 검토](ROOT-REVIEW.v1.json)는 소스 비작성자의 비맹검 검토이며 독립 실행 oracle이 아닙니다.
