# 요청 79개 변환 도구: 최종 준비 확인

기존에 컴파일한 도구의 파일 지문, 실제 연결된 공개 라이브러리 16개, 독립 검토의 소스 12개를 비교했습니다. 현재 소스 12개는 독립 검토가 읽은 파일과 바이트까지 같습니다. 실행 파일은 새로 만들거나 시작하지 않았습니다.

기존 합성 검사는 두 패키지에서 상위 검사 15개와 하위 검사 43개를 통과했습니다. 이 확인은 기존 검사 기록을 읽은 결과입니다. 실제 요청 79개 변환과 학습은 아직 하지 않았습니다. 공개 소스의 CI와 비공개 준비 도구의 로컬 검사는 별도의 증거입니다.

원형 v1과 검토 기록은 그대로 보존했습니다. 수정한 v2는 AUC 자료의 명시적 단위 가중치, 실행 가능한 자원 계획, 향후 학습 파일의 전체 예약량, 실행 시 CPU와 Go 메모리 설정을 검사합니다. Go 메모리 설정은 운영체제 전체 메모리의 강제 제한이 아닙니다.

실제 변환 전에 Root가 자원 정책과 파일별 보관량, 기존 학습 두 번과 모델 두 개의 소비량, 입력과 실행 파일의 지문, 외부의 일회성 실행 제어를 확정해야 합니다. 이 자료는 실행 승인이나 모델 성능 개선 증거가 아닙니다. 모델 본체와 비공개 절대 경로, 원본 데이터 본문은 포함하지 않습니다. 소스 사본은 검토용 일반 텍스트이며 이 준비 기록을 공개 CI에서 실행했다고 해석하면 안 됩니다.

이 빌드의 연결 근거는 기존 Go 빌드 메타데이터와 저장된 의존성 목록 및 현재 소스 지문입니다. 독립 컴파일러로 빌드를 재현한 증거는 아닙니다.
