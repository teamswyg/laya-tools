# 다음 학습 자료를 늘릴 배치 준비

[English](README.en.md)

이미 있는 초안 20개에서 원래 순서로 **다음 준비 대상 4개**를 골랐습니다. 목표 10개에는 **6개가 부족**합니다. 13개는 권리·정확한 원문·계약 준비가 덜 되어 보류했고, 3개는 이미 적격인 두 요청과 별도 반올림 작업이라 제외했습니다. 현재 적격 자료는 여전히 **요청 2개·후보 라벨 5개**입니다.

선정 대상은 숫자 쉼표 파싱, map 키 충돌, flag map 사본, 소수 bytes 파싱입니다. **입력 19개·후보 설명 12개·향후 호출 제안 57회**는 네 요청의 검사 계획입니다. 실제 후보 호출·새 정답·역할·적격화·모델·학습은 **0**입니다. 반복 입력이나 같은 helper를 독립 요청으로 더하지 않습니다. [전체 선택·보류 근거](BATCH-SELECTORS.v1.json)와 [상세 계획](PLAN.ko.md)을 보세요.

다음에는 실제 후보·adapter·원천·기대값·설명을 관측 전에 고정하고 family별로 같은 배치 절차를 재사용합니다. 원문이나 관측이 불완전하면 미시작 행과 실패를 보존합니다. 다른 revision이나 관측 뒤 기대값 수정으로 수를 채우지 않습니다.

이 자료는 소스 준비이며 원본 실행·라이선스 전체 계보 승인·학습 효용을 입증하지 않습니다. 기존 봉인과 Want는 그대로입니다. PR111 CI와 HF 개발 데이터 공개는 대기 중이며, 30/60 학습 체크포인트와 주장 도메인별 보호 평가 2,400개 목표를 유지합니다.
