# INI 두 작업의 실제 관측과 개발용 채택

아주 작은 모델이 여러 후보 중 도움이 될 **주장·힌트**를 제시하도록 만드는 실험입니다. 이번에는 INI 따옴표·주석 처리와 중복 섹션 삭제를 실제 Go 원본에 연결해 검증했습니다. 서로 다른 의미 요청은 **25 → 27개**, 후보 라벨은 **73 → 79개**가 됐습니다. 공개 학습 파일은 여전히 **23행**입니다. 연결 원천 그룹과 생성/reader 대응을 확인한 뒤 추가합니다.

| 작업 | 입력 × 후보 | 만족 / 불만족 / 미상 관측 | 세부 조건 참 / 거짓 / 미상 |
|---|---:|---:|---:|
| 따옴표 안의 주석 문자 | 5 × 3 | 9 / 6 / 0 | 21 / 7 / 2 |
| 중복 섹션 삭제 범위 | 5 × 3 | 10 / 5 / 0 | 32 / 5 / 2 |

각 정답 후보는 다섯 입력을 모두 만족했습니다. 기존 구현과 의도적인 오답 후보에는 각각 알려진 반례가 있습니다. 예를 들어 `k="a#b;c" # tail`에서는 따옴표 안의 `#`·`;`를 값으로 보존해야 합니다. 삭제 작업에서는 음수·범위 밖·없는 이름을 거부하고 유효한 중복 섹션 삭제를 유지해야 합니다. 기존 구현의 음수 삭제 뒤 getter 하나가 panic을 냈습니다. 그 뒤의 상태 두 항목은 **미상**이며, 이미 관측한 오류 종류의 반례와 별개로 보존합니다. panic 자체를 음성 정답으로 사용하지 않습니다.

[ROOT-QUALIFICATION.v1.json](ROOT-QUALIFICATION.v1.json)은 실제 비교 뒤 별도로 채택한 근거입니다. 정답·오답 텍스트와 입력/Want를 바꾸지 않았습니다. 미상 네 조건은 계속 미상입니다. 두 요청을 30관측이나 6후보만큼의 독립 문제로 늘려 세지 않습니다. 전체 풀은 **27요청·79라벨(양성27/음성52)·132입력·392원관측·388선택관측**입니다. 모든 새 라벨은 유한 개발용이며 가중치는1입니다.

범위에는 한계가 있습니다. 따옴표 처리는 고정된 단일 행 다섯 개이고, 모든 parser 옵션 조합을 실행한 것은 아닙니다. 삭제의 `x_indexes`는 공개 API로 확인한 발생 순서입니다. 내부 인덱스를 읽었다는 의미가 아닙니다. 삭제 전 검증과 기존 삭제 호출 사이의 동시성·원자성은 보장하지 않습니다. 관련 범위는 채택 파일에 명시했습니다.

두 원본 worker는 각각 한 번 시작하고 한 번 회수했습니다. 따옴표 작업은125프레임·최대 OS RSS6,553,600B·시작부터 회수까지0.9011초, 삭제는1499프레임·10,895,360B·6.5542초였습니다. 시작·저장 동기화 비용을 포함한 **관측 수집기** 수치입니다. 모델 추론·GPU·Go heap·전력·Codex 비용 측정으로 해석하지 않습니다. 그 뒤에는 저장된 결과만 비교했으며 원본을 다시 실행하지 않았습니다.

`source/comparer`에는 원본 본문 없는 자체 Go 비교기와 synthetic failure controls를 `.txt`로 보관합니다. 아래 검사는 이 소스를 임시 디렉터리에 복원해 race/vet를 실행합니다. 실제 원본이나 모델을 실행하지 않습니다.

```sh
bash scripts/verify-next60-ini-two.sh
```

실제 관측의 축약된 Want/Got는 `PREDICATES.*.v1.json`에 있습니다. 원시 journal·worker dump·바이너리는 공개하지 않고 해시로 참조합니다. 최초 수집 파일의 `pending`과25개 상태는 당시 기록입니다. 이후 비교 파일과 채택 파일이 다음 단계를 나타내며, 역사 기록을 소급 수정하지 않습니다. 이전 Sub/body 채택의 HF21·CI pending도 당시 상태이고, [별도 배포 근거](../publication-proof-120/README.ko.md)가 실제 HF23·PR119 병합을 기록합니다.

**30개 적격 요청 이전 새 학습은0회**입니다. 나머지 세 작업은 INI 총 입력 바이트 예산, bounded file read, 배타적 file write입니다. 후보 인덱스1을 항상 고르는 기준은24/27, 항상 음성인 기준은52/79이며 모델 정확도가 아닙니다. 이후 위치·어휘 대조, 원천 그룹 분리,60개 checkpoint·도메인별 보호2,400요청·효용5% 기준을 적용합니다.

자체 소스·문서는 Apache-2.0입니다. INI Apache 전문 고지와 비교용 Go BSD 고지를 보존합니다. 비교용 고지는 역사적인 모든 복사 계보를 승인하지 않습니다. 모델 가중치는 여기에 없습니다.
