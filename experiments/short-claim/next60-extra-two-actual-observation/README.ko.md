# 추가 두 요청: 실제 관측 → 비교 → 개발 데이터 편입

문자열 목록의 입력 한도를 지키는 작업과 여러 인자 검증 오류를 합치는 작업을 실제 Go 라이브러리로 실행했습니다. 요청별 고정 입력 5개에 원본·작성한 참조·작성한 반례 후보를 적용해 **30개 관측**을 얻었습니다. 이 관측들은 개발용 요청 두 개의 근거이며, 독립된 학습 요청 30개를 뜻하지 않습니다.

| 구분 | 실제 결과 |
| --- | --- |
| 문자열 목록의 개수 한도·CSV 처리 | 15개 관측, 정상 반환 15개 |
| 여러 검증 오류의 보존·호출 순서 | 15개 관측, 정상 반환 15개 |
| 고정 Want를 만족한 관측 | 23개 |
| 알려진 반례가 있는 관측 | 7개 |
| 전체 만족 여부를 판단하지 못한 관측 | 0개 |
| 개별 조건 | 만족 125개 / 불만족 15개 / 미상 1개 |

검증 오류 원본 후보의 한 입력에서 `B_code`는 얻지 못했습니다. 이 값은 `observable_unavailable`로 남겼습니다. 같은 관측에서 호출 횟수와 오류 타입에 관한 조건은 불만족이므로, 전체 관측은 알려진 불만족입니다. 미상 값을 거짓으로 바꾸어 계산한 결과가 아닙니다.

두 참조 후보는 각각 다섯 입력의 알려진 조건을 모두 만족했고, 나머지 후보는 각각 알려진 반례가 있습니다. Root가 이 유한 범위만 개발 데이터로 편입했습니다. 이전 21개 요청과 합치면 **23개 요청·67개 후보 라벨·113개 입력 변형**입니다. 보존한 관측은 335개, 후보 라벨에 선택된 관측은 331개입니다. 이전 네 미상 관측의 제외는 그대로 유지됩니다.

## 사람이 읽을 파일

- [FIXTURES.v1.json](FIXTURES.v1.json), [WANTS.v1.json](WANTS.v1.json): 실행 전에 고정한 입력과 조건.
- [SLICE-OBSERVATIONS.v1.json](SLICE-OBSERVATIONS.v1.json), [VALIDATORS-OBSERVATIONS.v1.json](VALIDATORS-OBSERVATIONS.v1.json): 실제 작업자 프로세스의 구조화된 반환값.
- [COMPARISON.v1.json](COMPARISON.v1.json): 저장한 관측과 Want의 비교. 이 파일 자체는 라벨 편입 권한이 없습니다.
- [ROOT-QUALIFICATION.v1.json](ROOT-QUALIFICATION.v1.json): 별도 Root 편입 기록. 정확한 요청·후보·선택 관측을 기록합니다.
- [FIRST-TRIALS.v1.json](FIRST-TRIALS.v1.json): **비교 이전**의 최초 실행 기록. 당시 `qualified=false`와 비교 대기 상태를 그대로 보존했습니다.

Root는 각 작업자에 대해 Start 1회·Wait 1회·종료 코드 0·회수를 확인했습니다. 당시 작업자 최대 RSS는 문자열 목록 6,537,216바이트, 오류 검증 6,488,064바이트였습니다. 제어기가 측정한 실행·대기 시간은 각각 약 0.651초, 0.489초입니다. 이 수치는 파일 저장과 프로세스 시작이 포함된 작은 관측 도구의 측정입니다. **Laya 모델의 추론 속도, GPU 사용량, 모델 라우팅의 절감 효과를 측정한 수치가 아닙니다.** Go 힙 제한은 소프트 제한이고 RSS 기준은 실행 후 확인입니다.

## 에이전트와 CI에서 사용

저장 결과를 다시 비교하는 검사는 다음 명령으로 실행합니다.

```sh
bash scripts/verify-next60-extra-two.sh
```

저장 결과의 지문을 검사하고, Go 배열 기반 비교기로 30개 관측과 141개 조건을 다시 계산한 뒤 저장 비교와 필드별로 대조합니다. 잘린 입력, 중복 필드, 변형된 조건, 미상 처리 오류에 관한 합성 검사도 수행합니다. 이 검사는 원본 후보 프로세스나 모델을 실행하지 않습니다. 원본 실행 당시의 비공개 저널·저장 확인·프로세스 회수는 최초 Root 실행의 검증 범위입니다. 공개 CI는 그 비공개 저널의 확인을 재현한다고 주장하지 않습니다.

`source/`에는 작성한 Go 관측기·저장기·외부 제어기·비교기를 `.go.txt`로 보관했습니다. CI는 임시 디렉터리로 작성한 모듈만 복원합니다. 원본 라이브러리 본문, 바이너리, 모델 가중치, 로컬 경로, 원시 저널은 이 공개 묶음에 포함하지 않습니다. `native-*` 자료는 원본 소스를 별도로 확보해야 하는 실행 구성의 기록이며 CI가 복원하는 대상이 아닙니다.

## 다음 학습에서의 의미

이 데이터는 ‘후보가 조건을 만족할 가능성을 알려주는 작은 힌트 모델’을 위한 개발 자료입니다. 사람이 읽는 문장을 잘 생성하는 모델을 평가하지 않습니다. 요청의 20/23개에서 참조 후보가 2번 위치에 있고, 후보 라벨의 44/67개는 음성입니다. 두 수치는 분모가 다르며 모델 정확도가 아닙니다. 후보 순서를 바꾸는 평가와 의미군 단위 분할이 필요합니다.

이번 편입으로 새 Fit, 특징 추출, 모델 점수 계산, 모델 활성화는 수행하지 않았습니다. 새 학습의 첫 기준은 **검증된 서로 다른 요청 30개**이며, 이어서 60개 개발 체크포인트와 주장하는 도메인별 2,400개 보호 평가를 구분합니다. 23개는 학습 준비가 진전됐다는 뜻이며 실제 사용자 작업의 비용·시간 개선을 입증한 숫자가 아닙니다.

작성한 자료는 저장소 Apache-2.0 조건을 따릅니다. 원본 pflag·Cobra 및 선택된 Go 코드의 고지는 [notices/](notices/)에 보존했습니다. 로컬 연구 실행 검토와 이후 원본 소스·바이너리·모델 배포 검토는 범위가 다릅니다.
