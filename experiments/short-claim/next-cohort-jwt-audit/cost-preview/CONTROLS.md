These tests belong to the unchanged cost-worker package after Root stages the
exact main.go/go.mod and this test source together. This scratch directory has
no worker copies, JWT source replacement, compiler invocation or test binary.
No Go commands, package initialization, native API, crypto operation, model or
Fit execution has occurred during authoring.

The first test-source bytes are retained in FIRST-CONTROLS-AUTHOR-FULL. Final
source adds only explicit parentheses around pointed-counter increments for
readability; there was no formatting, compilation or runtime finding. The final
full packet retains the final test and this document plus exact original worker
main/module/protocol references to the prior complete author archive. The
original worker main.go, go.mod, protocol and author archives remain unchanged.

The controls use entirely synthetic audiences, dates, integer modulus values,
invalid token strings and error trees. They do not borrow the 13 real tokens,
first API outcomes or the four request labels. Tests inspect the manual-order
output only to determine where the expired operation stopped, never to judge
whether a candidate solves a request.

Coverage:

- Preserve nil dates and nil-versus-empty audience identity.
- Break source and cross-field NumericDate aliases and spare audience capacity;
  mutations in either source or copied values cannot escape ownership.
- Own the public-key modulus using tiny synthetic integers, never RSA operations.
- Distinguish token/full DER/method/decoder/source cache-key contexts and fresh
  parent state. This is a key-value contract test, not native lookup/hit coverage.
- Verify all normalized policy-mask bits and generic invalid-claims wrapper
  parity. A generic wrapper without a recognized policy cause remains unknown.
- Preserve unknown for arbitrary Is/Error behavior, nil children, empty unwrap,
  crypto/input/context causes, unwrap cycles and panic. Unknown mixed with a
  known refusal must never become an observed false.
- Check inclusive depth 8 and 32 visited-node limits and reject the next boundary.
- Keep canonical claim hashing independent of copy mutation and reject fractional
  precision instead of producing a usable identity.
- Stop expired-deadline operations before key copying, option construction,
  parser/validator/cache work. Retain the named-return parent elapsed record
  and exactly one candidate/fixture attempt; do not advance after unknown.
- Require the direct expired trial to return `unknown_deadline` and zero
  counters, so a recovered nil-key/cache panic cannot impersonate the guard.

The deadline test deliberately passes a nil public key and empty synthetic
fixtures. The current guard returns before any key dereference/native API call.
If that guard regresses, source-local counters/ownership failures expose the
problem without supplying a token or usable crypto key. Tests do not call
ParseWithClaims, NewParser, NewValidator, Validate or candidate option APIs.
