# 공개 시점 152의 파일 보존본

JWT 캐시 비용 실험을 공개한 커밋 [`1f6b84c`](https://github.com/teamswyg/laya-tools/tree/1f6b84c91e1931001f1ffa6dddc95e9c9c9ac092)의 공용 파일 5개를 원문 그대로 보관합니다. 이후 README와 CI가 바뀌더라도 당시 실험의 체크섬을 재현하기 위한 자료입니다.

`files/`에는 당시 루트 README 두 개, CI 설정, 보안 검사 설정, 검증 스크립트가 있습니다. 이 폴더의 CI·보안 설정과 스크립트는 보관 자료이며 실행 설정으로 사용하지 않습니다. 파일 내용과 기존 저작권·출처 표시는 그대로입니다. 저장소의 Apache-2.0 라이선스가 적용됩니다.

`ORIGINAL-SHA256SUMS.publication152.txt`는 상위 실험의 기존 45행 체크섬 파일과 바이트까지 같습니다. `SHA256SUMS`는 보존본 5개만 검사합니다. 현재 검증 스크립트는 기존 체크섬 파일을 변경하지 않고, 정확히 이 5행만 보존본에 연결합니다. 나머지 40행은 현재 실험·재생 코드 파일을 계속 검사합니다. 새로운 외부 경로는 허용하지 않습니다.

현재 `scripts/verify-jwt-cost-preview.sh`는 이 연결 기능을 추가한 새 검증기입니다. `files/scripts/verify-jwt-cost-preview.sh`는 당시 검증기의 원문입니다. 현재 공용 문서·CI·보안 설정의 변경은 현재 저장소 검사에서 검토해야 하며, 이 보존본 검사가 대신 승인하지 않습니다. 첫 실패 CI 기록이나 실험 결과를 바꾸지 않습니다. 실행 시 Git 기록이나 네트워크가 필요하지 않습니다.
