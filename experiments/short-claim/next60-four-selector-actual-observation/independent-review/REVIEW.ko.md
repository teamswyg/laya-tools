# 네 작업의 저장 결과 검토

고정된 입력 19개에 대한 후보 관측 57개를 원래 Want와 비교했습니다. 네 작업 모두 후보 1이 해당 작업의 모든 입력을 만족했습니다. 후보 0과 2에는 각각 실제로 관측된 반례가 있습니다. 전체 결과는 **일치 40개, 알려진 불일치 17개, 판정 불가 0개**입니다.

| 작업 | 후보 0: 일치/불일치 | 후보 1: 일치/불일치 | 후보 2: 일치/불일치 |
| --- | ---: | ---: | ---: |
| 엄격한 정수 쉼표 문법 | 3/3 | 6/0 | 3/3 |
| Name 키 충돌 거부 | 2/2 | 4/0 | 2/2 |
| 지도 스냅샷의 독립성 | 2/2 | 4/0 | 2/2 |
| 소수 바이트 크기의 정확한 계산 | 3/2 | 5/0 | 4/1 |

이 표는 요청 4건의 제한된 동작 근거입니다. 입력 19개나 후보 관측 57개를 독립적인 요청으로 세지 않습니다. 후보 이름이 `reference`라서 일치로 판단한 것이 아니라, 오류 존재 여부와 필요한 값·키·지도 상태를 모두 비교했습니다. [상세 비교](FINITE-COMPARISON.v2.json)에는 입력 19개마다 후보 세 개의 검사 결과가 있습니다.

쉼표 작업에서 원본 기반 후보 두 개는 `12,34`와 `1,,234`를 허용했습니다. 양의 int64 범위 초과에서는 오류를 반환했지만, 요구한 0 대신 `9223372036854775807`도 반환했습니다. 오류가 있다는 사실만 확인했다면 이 차이를 놓쳤을 것입니다. 두 후보는 같은 원본 함수를 사용하므로 독립 구현 두 개라고 주장하지 않습니다.

키 충돌 작업은 `NAME/name`과 `NAME/Name`을 모두 거부해야 합니다. 후보 1은 대상을 `old`로 유지하면서 정렬된 충돌 키와 오류를 반환했습니다. 값이 같거나 정확한 대소문자 키가 있어도 충돌을 숨기지 않았습니다. 원본의 지도 탐색 순서가 앞으로도 같을 것이라고 가정하지 않았습니다. 이번에 선택된 이름과 관계없이 요구된 충돌 오류가 없다는 점이 반례입니다.

스냅샷 작업에서는 두 방향의 변경을 따로 확인했습니다. 후보 1은 스냅샷 변경이 원본 지도에, 원본 지도 변경이 스냅샷에 퍼지지 않았습니다. 원본과 지도를 담은 구조체만 복사한 후보는 변경이 서로 퍼졌습니다. 초기 `nil` 지도와 빈 지도도 구분했습니다. 없는 플래그의 결과는 빈 비nil 스냅샷과 `*pflag.NotExistError`이며, 별도로 만든 `items` 지도는 계속 nil입니다. 이 결과는 공유 지도를 반환하는 고정된 pflag 버전에 한정합니다.

바이트 작업에서는 `MaxUint64.0`과 `MaxUint64-0.1`이 유효한데 원본 부동소수점 경로는 거부했습니다. 반대로 먼저 소수 부분을 잘라낸 후보는 `MaxUint64+0.9`를 허용했습니다. 정확한 후보는 잘라내기 전에 범위를 확인했습니다. 큰 값은 숫자로 변환해 비교하지 않고 정확한 십진 문자열로 비교했습니다. 다섯 소수 입력은 전체 문법·유니코드·모든 단위·정수 경로의 실행 검증을 대신하지 않습니다.

Want의 선택 필드가 null이면 해당 조건을 요구하지 않습니다. 관측하지 못한 값이 null인 경우와 구분합니다. `error_present=false`도 반드시 검사하고, 필요한 오류 종류·타입, 반환 값, 정렬 키, 지도의 nil 여부와 항목을 모두 비교했습니다. 오류 문장 자체를 같게 만들라는 Want는 없었습니다. 이번 57개에는 필요한 비교 채널의 판정 불가가 없지만, 원본 내부·초기화 호출 수는 여전히 계측하지 않은 null입니다.

검토자는 Want·후보·관측기·원본 바인딩·외부 작업자를 작성하지 않았습니다. 실행 전에 소스와 Want를 검토했고 후보 설계 이름을 알고 있었으므로 맹검 평가가 아닙니다. 저장 JSON을 비교하는 첫 필터는 괄호 오류로 실패했고, 원본 필터·빈 결과·진단을 보존한 뒤 새 필터로 수정했습니다. 원본 실행을 반복하거나 Want를 바꾸지 않았습니다.

Root의 기록에는 시작·종료 대기 각각 한 번, 후보 반환 57회, 직접 오류 메서드 반환 14회, panic 0회가 있습니다. 작업기 최대 RSS 8,273,920바이트와 전체 자식 시간 약 1.078초는 숫자 관측과 기록을 수행한 작업기의 측정값입니다. **모델 추론·GPU 성능·Codex 절감 효과의 측정값은 아닙니다.**
