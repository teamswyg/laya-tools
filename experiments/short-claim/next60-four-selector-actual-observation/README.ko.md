서로 다른 요청 4개에 대해 원본·대안 후보를 한 번 실행했습니다. 입력은 19개, 후보 위치는 12개, 저장된 후보 관측은 57개입니다. 이를 57개의 독립 요청이나 원 API 호출 수로 세지 않습니다.

| 작업 | 원본 후보 0 | 대안 후보 1 | 다른 후보 2 |
| --- | ---: | ---: | ---: |
| 쉼표 문법 | 3/6 | 6/6 | 3/6 |
| 키 충돌 | 2/4 | 4/4 | 2/4 |

표는 고정 입력의 전체 기대 조건을 만족한 수입니다. 작성자가 아닌 동료가 저장된 결과를 비교했습니다. 전체 40개 일치·17개 알려진 불일치·판정 불가 0개이며, 후보 패닉과 오류 문자열 읽기 패닉도 0개였습니다. 후보 1은 네 작업 모두 만족했고 다른 후보 여덟 위치에는 반례가 있습니다. source/Wanted를 먼저 본 검토이므로 비맹검입니다.

작업자 전체의 최대 RSS는 **8,273,920B, 약 7.89MiB**입니다. 시작·입력 검사·관측·기록 저장을 포함한 시간은 **1.077920459초**, OS user/system 시간은 0.01/0.04초입니다. 매 관측의 동기화 저장이 포함된 값으로, 모델 추론 속도·Go 힙·GPU 메모리 측정이 아닙니다. 동기화 기록 142개, 실제 후보 반환 57개, 오류 메서드 반환 14개를 저장했습니다. 원 API 내부 호출과 초기화 수는 계측하지 않아 `null`로 유지합니다.
