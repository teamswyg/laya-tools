# Next observation 77: source-first selection of two behavior goals

Select **ordered logfmt record decoding** and **dataurl byte percent conversion**. These are two existing proposals from source-audit74, narrowed for a small next observation. No parents or truth labels were added. Only the pinned sources were read. Original functions, package initialization, tests, and models were not executed, and no Wants were authored.

For logfmt, observe [decode.go](https://github.com/go-logfmt/logfmt/blob/804e98fff868b206344991c57a8182172e5ba41e/decode.go): `NewDecoder` or `NewDecoderSize → ScanRecord → ScanKeyval → Key/Value → Err`. Preserve key/value sequence and duplicates rather than overwriting them in a map. Keep nil distinctions for bare keys, empty values, and empty quoted values. Preserve successful items before an error separately from the Key/Value at the failing step. Record `*SyntaxError` Msg, Line, Pos, and its message without treating the locations as character indexes. EOF has a nil Err, and the first error stops further progression.

Key/Value may borrow the current line buffer and are valid only until the next ScanRecord. The observer must copy nil status, length, and exact bytes into its own arrays before advancing. Observer-owned copies do not imply that the original API returns owned snapshots. Quoted escapes use `unquoteBytes/getu4` in [jsonstring.go](https://github.com/go-logfmt/logfmt/blob/804e98fff868b206344991c57a8182172e5ba41e/jsonstring.go), which allocates new storage on some paths. The decoder has no goroutine or shared-state writes, but accepts a Reader. Limit this observation to in-memory string readers, excluding arbitrary callbacks, files, and networks. Scanner may read ahead, so exact consumed input bytes are not asserted.

For dataurl, directly observe only [rfc2396.go](https://github.com/vincent-petithory/dataurl/blob/d1553a71de50473073e188aa79cebf7f993f20fe/rfc2396.go): `Escape → isUnreserved` and `Unescape → isHex/unhex`. Escape iterates bytes and formats other bytes as uppercase hex percent escapes. Unescape reads ASCII input and does not convert plus to space. Its decoded bytes need not be valid UTF-8, so retain nil status, length, and hex. Malformed escapes or raw non-ASCII input return nil bytes with an error. These are freshly constructed errors rather than shared sentinels. Both invalid-hex branches use the current rune in their messages; observe this behavior rather than improving the message. Exclude raw invalid UTF-8 from this scope. Preserve the nil status of successful empty output too.

Exclude full `DecodeString` this time. The parser in [dataurl.go 199–252](https://github.com/vincent-petithory/dataurl/blob/d1553a71de50473073e188aa79cebf7f993f20fe/dataurl.go#L199) can return early after unescape, unquote, or base64 errors. [lex.go 151–192](https://github.com/vincent-petithory/dataurl/blob/d1553a71de50473073e188aa79cebf7f993f20fe/lex.go#L151) uses a goroutine and unbuffered channel without parser-return cancellation, draining, or joining. A later emit can therefore block on a source-visible path. This does not mean every malformed input leaks a goroutine; no leak was measured. Also exclude `Decode(io.Reader)` and its ReadAll, external Writers, environment/file APIs, and encoder callbacks.
