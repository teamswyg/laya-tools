# 21개 유한 개발 요청

[English](README.en.md) · [다섯 작업의 실제 관측](../next60-five-actual-observation/README.ko.md)

작은 주장 모델의 다음 학습을 준비하는 **개발용 자료**입니다. 모델은 후보에 대한 힌트를 주며, 테스트나 사람이 확인한 근거가 최종 판단을 합니다. 이 자료를 읽거나 검증해도 모델을 학습하거나 실행하지 않습니다.

기존 16행의 바이트를 보존하고 서로 다른 요청 5개를 추가했습니다. [데이터](data/train.jsonl)는 28,800바이트, 요청 21개·후보 정답 61개(양성21/음성40)입니다. 입력 103개에 대한 원관측 305개가 근거이며, 선택한 후보에 속한 관측은 301개입니다. 입력 변형이나 후보 수를 새 요청 수로 세지 않습니다.

오류 writer 원본 후보의 반환값은 알 수 없으므로 그 후보와 관측4개를 학습 선택에서 제외했습니다. 판단 불가를 거짓으로 바꾸지 않았습니다. 다른 후보의 알려진 반례와 별도의 미상 조건은 함께 보존했습니다. [Root 채택 근거](ROOT-QUALIFICATION.v2.json), [실제 생성 기록](MATERIALIZATION.v1.json), [실제 Go reader 검증](INPUT-VALIDATION.v1.json)을 별도로 확인할 수 있습니다.

Go 생성기는 고정된 자료·채택 근거를 대조하고 파일과 부모 폴더를 동기화했습니다. 별도 검증기는 정답을 새로 정하지 않고 21행을 실제 reader로 읽어 요청·후보 문장, ID, 출처, 정답, weight와 수량을 확인했습니다. Features·Score·Project·Fit·원본 후보·모델 호출은 모두0입니다. 생성기 검토자는 후보/정답/생성기 작성자가 아니지만, 비교기와 reader 검증기 작성자이며 비눈가림 검토라는 범위를 공개합니다. 자신의 검증기를 독립 검토했다고 주장하지 않습니다.

저장소 루트에서 다음 명령으로 저장 관측의 비교와 데이터 생성·reader 검증, 소유 코드의 합성 오류 검사를 확인합니다. Go1.27.1과 race 검사에 필요한 C 컴파일러가 필요합니다. 원본 관측 worker는 다시 실행하지 않습니다.

```sh
bash scripts/verify-next60-development.sh five
bash scripts/verify-next60-development.sh data
bash scripts/verify-next60-development.sh twentyone
```

CI는 같은 검사 결과를 재현합니다. 새 단계에는 모델 학습·추론이 없으며 전체 CI에 이미 있는 Laya native inference 단계는 별도입니다. 검사 파일은 `source/`에 실행되지 않는 `.go.txt`로 보존하고 CI가 임시 모듈에 복사해 실행합니다. `independent-validator-preparation/`은 실제 실행 전 준비 기록이며, 현재 완료 여부는 위 실제 검증 파일에서 읽어야 합니다.

두 번째 후보만 고르면 18/21≈85.7%인 위치 편향이 있습니다. 후보를 전부 음성이라 부르면40/61≈65.6%이며 서로 다른 단위입니다. 두 값은 모델 정확도가 아닙니다. 원천 그룹76·77·78을 재사용하므로 새 원천 일반화도 입증하지 않았습니다. 적격 요청30개 전에는 새 corpus 학습을 시작하지 않습니다. 이후60개 점검과 주장 도메인별 보호 평가2,400개, 단순 기준 대비 효용5% 기준을 유지합니다. 모델 개선·실제 Codex 절감은 아직 미입증입니다.

이 폴더에는 모델 본체·실행 파일·사설 경로·원시 journal이 없습니다. 이전 공개 자료는 [HF16 불변 버전](https://huggingface.co/datasets/JooYoon/riidolaya-shortclaim-next60-development/tree/next60-16-finite-v1)에 있습니다. **21개 자료의 HF 게시 여부는 별도 게시 증거로 확인해야 하며 이 README만으로 게시 완료를 뜻하지 않습니다.** 자체 자료는 저장소 Apache-2.0을 따르고 원본 라이브러리의 고지는 다섯 작업 관측 폴더에 전문으로 보존합니다.
