# 21개 자료 생성기 독립 검토

봉인된 Go 생성기 전체 소스·검사와 Root의 실제 생성 자료를 읽어 검토했습니다. 현재 고정된 입력과 출력에서 수정이 필요한 구체적 결함은 0개입니다. 검토 중 Go·reader·원본·모델을 다시 실행하지 않았습니다.

생성기는 Root가 이미 부여한 `truth`를 복사합니다. `source_candidate_position==1` 검사는 봉인된 자료의 형태가 맞는지 확인하는 조건이고, 출력의 라벨 값은 실제 Root truth 포인터에서 가져옵니다. 관측 불가만 있는 음성을 거부하고, 알려진 반례와 다른 unknown이 함께 있는 음성은 그대로 허용합니다. 양성은 모든 행이 satisfied이고 unknown이 없어야 합니다.

오류 writer 원본 후보는 학습 자료에서 제외됐습니다. reference는 학습 위치 0으로 이동하지만 원 위치 1과 metadata_id=reference-design은 채택 장부에 보존됩니다. 새 후보 수는 3/2/3/3/3입니다. 새 5행의 요청·설명을 Wanted와 채택 기록 양쪽에 대조했고, 라벨·ID·role·unit weight·그룹·원본 SHA·text revision도 일치했습니다.

기존 16개 접두부 22,097바이트의 SHA와 마지막 LF를 독립 확인했습니다. 생성 파일은 28,800바이트, SHA-256 `f8d9beb88393d2c1d2d8f690e366342157fd13bee25abb79078287e62c94b828`입니다. 최종 합계는 21개 요청·61개 라벨·양성 21·음성 40·입력 103입니다. 선택 후보 관측은 301개이고, 제외 후보까지 포함한 원 실행 증거는 305개입니다. 새 자료에서는 각각 65개와 69개입니다.

후보 위치 1만 고르는 대조군은 18/21 약 85.7%이고, 후보별 모두 음성 대조군은 40/61입니다. 서로 단위가 다르며 모델 정확도가 아닙니다. 위치·후보 이름·문체 단서는 이후 별도 실험에서 검증해야 합니다.

생성기는 고정 배열과 타입이 명확한 슬라이스를 사용하고, 단일 호출에서 공유 map이나 lock이 필요하지 않습니다. 입력 세 파일의 전체 SHA를 먼저 확인하므로 일부 생략된 Root metadata도 원문 전체에 묶입니다. 출력은 새 경로에만 생성하고 기존·부분 출력은 보존합니다. 파일과 부모 디렉터리의 Sync가 성공한 뒤 complete를 기록합니다. 이것이 전원 장애나 저장 장치 내구성을 보증하지는 않습니다. 메모리 한도는 soft limit이며 실제 RSS·GPU·SIMD 성능을 측정한 기록이 아닙니다.

작성자의 저장된 합성 로그를 재계수해 상위 4+하위 16개 통과를 확인했습니다. 합성 테스트를 재실행하지 않았습니다. float 전용 검사가 있었다고 주장하지 않습니다. 숫자 metadata는 int 필드로 디코딩되고, 현재 전체 SHA가 고정된 입력 계약에서 추가 검사를 요구할 구체적 결함은 없었습니다.

검토자는 생성기·Wanted·후보·Root 채택의 작성자가 아닙니다. 이전 자료와 소스를 아는 눈가림 없는 검토이며, 5개 작업의 저장 비교기와 21개 reader 검증기는 이 검토자가 작성했습니다. 따라서 자신의 검증기를 독립 검토했다고 표현하지 않습니다. Root의 실제 reader 실행은 별도 증거입니다. 이전 source/QA의 pending 상태는 역사적 기록으로 보존합니다. 이 검토가 포괄적인 라이선스 승인·일반 정확성·모델 개선·비용 절감·새 CI 통과를 의미하지 않습니다.
