# 35행 공개 준비와 PR125·저장 공간 검증

[35개 개발 요청](../next60-development-thirtyfive/README.ko.md)의 저장 관측·Go 생성·실제 Reader 대조와 공개 경로 재현을 기록합니다. 새 두 요청에서 라벨6개를 채택했으며 전체35요청·102라벨입니다. 새 모델 학습은0회입니다. [로컬 오프라인 검사](PUBLIC35-OFFLINE-REPRODUCTION.actual.public.v1.json)는 전체 저장 판단309개와 데이터48,618바이트를 재현했습니다. 새35행 CI와 HF35 게시는 아직 후속 단계입니다. 현재 HF 고정판은33입니다.

[PR125](https://github.com/teamswyg/laya-tools/pull/125)는 [실제 CI](https://github.com/teamswyg/laya-tools/actions/runs/37119939397)의 Linux·macOS·secrets·quality 네 필수 작업이 통과해 봇이 병합했습니다. 기존 Laya native 검사도 양 플랫폼에서 각각 통과했으나 GPU 실행은 확인하지 않았습니다.

Linux의 전체 실제33행 비학습 결과와 차이 파일을 보존합니다. 미세한 부동소수점 차이가 정확한 동점을 만들었고, 순열 결과의 순서6건·모의 확인6건이 달라졌습니다. 독립 저장 파일 감사가219경우·876순위·2,628점수 위치·전체 합계와 차이 파일을 재계산했습니다. 실제 strict tie 정렬을 그대로 검사하고 견고한 점수쌍1,868개는 순서를 유지했습니다. Mac 고정값이나 production 점수·동점 처리 코드를 변경하지 않았습니다. 순열 BM25의 모의 확인은Mac258·Linux255지만, 둘 다 실제 업무 절감 수치는 아닙니다. FMA 원인은 추정이며 증명하지 않았습니다.

완료한 HF33 임시 공개 사본 두 묶음의334개 파일을 Go로 압축 보관했습니다. 원본 삭제 전 새 디렉터리에 전체 바이트·해시·권한을 실제 복원 확인했고, 동기화한 기록과 파일별 삭제 ACK를 남겼습니다. 독립 저장 감사는gzip 단일 스트림·425 tar 항목·빈 파일83개·672개 연결 기록을 확인했습니다. 보수적 확보량은1,235,478바이트이며 RAM 사용량이 아닙니다. 전체 연구 보관512MiB 한도와 기존 실패·원시 증거는 그대로 유지했고, 기존 집계20개와 새 완료5+2개를 합친 압축 기록은27개입니다. 이전 다섯 바이너리 압축과 합쳐도10MiB 확보 목표는 달성하지 않았습니다.

압축 도구의 처음 실패한 합성 검사와 수정 소스를 함께 보존합니다. macOS에서 새 일반 파일을 만들면 부모 디렉터리 링크 수가1 늘어날 수 있어 정확한 marker 한 개를 확인하는 구간만 그 변화도 허용했습니다. 권한·inode·device와 전체 파일 목록 검사는 유지합니다. [Go 합성 검사](archive-source/verify.sh)는 개인 연구 디렉터리를 복원·삭제하지 않습니다. 여기에 압축 payload, raw journal, 원본 라이브러리 본문, 모델 본체와 로컬 경로는 게시하지 않습니다. 감사 스크립트는 maintainer용 보조 자료이며 런타임은 Go입니다.

35행 공개 준비에서 단어 경계 없는 사용자명 검사 오탐과 private 모듈 경로를 검출한 실패도 보존합니다. 고정 과학 자료는 바꾸지 않고 공개용 경로만 템플릿으로 바꿨습니다. 약60개 준비 뒤에도 후보 위치 편향·원천 중복·역할 분리를 검토해야 하며, 보호2400개 평가와 실제 전체 확인 작업5% 개선 기준은 아직 남아 있습니다.

공개 묶음의 독립 저장 검토는 처음 모듈 경계 문제를 지적했고, 소스 내용 변경 없이 native 스냅샷12개를 .go.txt로 바꾼 뒤 전체 핀·값 일치를 확인했습니다. 최초 전체 Go 검사의 setup 실패와 수정 후 통과를 별도로 기록했습니다. source-only 기록을 잘못 제외한 *.so* 설정도 공유 라이브러리 패턴만 좁혀 수정했고, 현재 Git에 포함한 전체 파일을 목록과 대조합니다. [최종 공개 검토](public35-independent/REVIEW.public.v1.json)는 원본 실행이나 모델 학습을 하지 않았습니다.
