# Golden Reader v2 소스 초안

기존 Reader는 Boolean 정답 후보1..8개에서 양성0개·여러 개를 이미 허용합니다. 기존35개 자료의 후보2/3개·양성1개는 수집 결과의 범위이지 Reader의 양성 개수 제약이 아닙니다. v1과 모든 기존 바이트는 그대로 둡니다.

새20→60 coverage 계획은 후보5/8개×verified0/1/many/U/ambiguous의10개 셀을 다룹니다. 이 소스는 새 자료나 정답을 만들지 않습니다. Root의 별도 qualification/role-group/row/authority SHA를 먼저 확인하고, 후보8개 전체와 활성5/8개를 고정 배열로 보존합니다. T/F/U와 조건별 availability/known을 보관합니다. F+U는 알려진 반례 음성으로 남길 수 있지만 U-only는 null 정답·가중치이고 학습에서 제외합니다. 해석이 모호한 부모는 모든 후보 정답·가중치를 보류합니다. verified0은 계획의 any-U 문구를 보수적으로 적용하며 Root가 그 정확한 의미를 고정해야 합니다.

입력 접근자는 요청·후보의 원문/정규화 텍스트만 돌려주며 정답·ID·순서 번호·마스크·가중치·원천·역할을 특징으로 넣지 않습니다. 기존 Project는 known 부모의 모든 후보를 Known으로 만들므로 mixed-U를 바로 연결할 수 없습니다. 새 투영과 평가 계약은 별도입니다. 구조 검사와 핀 일치는 의미·권리·역할 그래프나 Fit 허가를 대신하지 않습니다.
