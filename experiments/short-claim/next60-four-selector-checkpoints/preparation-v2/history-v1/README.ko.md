기존 네 요청의 체크포인트 작업자 소스 초안입니다. 원래 순번 1/4/5/9, 입력 19개, 후보 위치 12개와 예정 호출 57개를 유지했습니다. 입력 19개는 요청 19개가 아닙니다. [원 fixture](FIXTURES.v1.json)와 v2 어댑터 여섯 파일은 원 바이트를 복사했습니다. 실제 호출·테스트·빌드·새 레이블·역할·학습은 모두 0입니다.

[writer](code/checkpoint/writer.go.txt)는 새 디렉터리와 파일을 배타적으로 예약하고 최초 예약과 디렉터리를 동기화합니다. 후보 호출 전, 후보 반환 후 오류 메서드 호출 전, 오류 메서드 반환 후와 후보 완료 시점마다 값 스냅샷을 저장합니다. 오류 메서드 전에는 반환값·상태·오류 존재와 타입만 알려진 값이며 오류 문장은 아직 관측하지 않았습니다. 스냅샷은 고정 배열과 값만 포함하며 원 오류 객체를 저장 함수에 전달하지 않습니다.

기록 쓰기나 동기화가 실패하면 실패 상태를 유지하고 다음 호출을 막습니다. 마지막 동기화 완료 프레임과 실패한 물리 파일 접미부를 구분합니다. 살아 있는 프로세스는 불완료 최종 결과를 한 번 저장할 수 있지만 외부 종료 뒤 호출 수를 추정하거나 최종 저장을 재시도하지 않습니다. `Observe_calls_returned`는 호출을 거부하고 반환한 Observe도 포함하므로 실제 후보 호출 수와 별개입니다.

[계획 초안](PLAN.draft.v1.json)은 동결되지 않았습니다. 이벤트 32 KiB, 최종 결과 256 KiB, 세 출력 파일 합계 1 MiB 미만을 제안합니다. 기록에 최종 결과용 256 KiB를 남겨 두며 부족하면 중단합니다. 오류 메서드는 예상 14회와 최대 57회를 구분합니다. 원 패키지 내부·getter·setup·init 호출은 계측하지 않았고 null로 남습니다. 저장 bytes는 메모리·RSS 측정이 아닙니다.

[runner](code/checkpoint/runner.go.txt)는 원 fixture의 47,256 B와 SHA를 먼저 확인한 뒤 정해진 배열 순서만 실행 입력으로 투영합니다. Wanted·truth·labels·roles·weights는 실행 입력이나 특징으로 사용하지 않습니다. Wanted 비교와 자격 판정은 후속 별도 단계입니다. 후보의 panic/진단 unknown은 관찰로 남기고, 체크포인트 또는 Observe 기계적 오류가 후속 호출을 중단합니다.

모든 Go 소스는 `.go.txt`, 모듈 초안은 `.mod` 역할의 `.txt` 파일로 보관했습니다. [native binding](code/nativebinding/native_binding.go.txt)은 원 패키지 import를 필요로 하며 전체 원천·의존성·모듈·라이선스·컴파일러 선택이 아직 준비되지 않았습니다. 원 패키지 init은 main 전에 일어나므로 작업자 내부 plan 검사로 startup을 허가할 수 없습니다. Root의 바깥 단일 실행 예약, 물리 경로 분리, 바이너리 핀, 최소 환경과 60초 process-group/Wait 결속이 먼저 필요합니다. 기존 controller와의 호환은 아직 확인하지 않았습니다.

[합성 테스트 소스](code/checkpoint/writer_test.go.txt)는 저장 완료가 Error()보다 앞서는지, 실패 접두부·순서·용량·복사·오류 메서드 panic·최종 저장 재시도 금지를 검사하도록 작성했습니다. 실행하지 않았으므로 통과 주장이나 컴파일 가능성 증명이 아닙니다. 준비자는 기존 v1/v2 어댑터 저자이며 독립 의미 검토자가 아닙니다. 수동 독해에서 plan null/누락 필드, macOS 임시 디렉터리 alias, 내부 호출 수 발명 거부를 보강했고 실행 실패로 주장하지 않습니다.

와이어 필드와 아직 미관측인 채널은 [스키마 명세](SCHEMA.v1.json), 원본 복사 핀은 [복사 장부](COPY-IDENTITY.v1.json), 모든 새 파일과 작성 장부는 [인계](HANDOFF.v1.json)에 있습니다. 원문 본문·호스트 경로·바이너리·원 로그는 이 묶음에 포함하지 않았습니다. 라이선스와 공개 취득 조건은 원 source selector와 별도 Root 원천 아카이브에 결속해야 하며 이 초안이 권리를 승인하지 않습니다.
