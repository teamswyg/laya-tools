현재 버전은 [v4](preparation/BOUNDED-REQUEST-SUPERVISION.v4.json)와 [최종 인계 v2](preparation/FINAL-HANDOFF.v2.json)입니다. [독립 검토](review-v4/REVIEW.v1.ko.md)는 명시된 입력 범위에서 직접 선택 API의 충족 제안3개와 불충족6개를 확인했습니다. 학습 정답·역할·가중치·그룹은 기존 파일에서 null을 유지합니다. 요청은27·32·21단어이며512 B·32단어 한도를 늘리지 않았습니다.

고정 모델 비교에 쓰는 [별도 한정 평가 기준](../caption-inference-76/rubric/riido-caption-inference76-root-truth.ko.md)은 전체9개 후보를 양쪽 설명에서 평가합니다. 정보가 부족한 A 후보를 빼지 않습니다. 학습 자료 편입, 독립 final 평가 또는 보편적인 함수 정답을 승인한 기준은 아닙니다. A/B·번역·반복 호출은 같은3개 논리 요청입니다.
