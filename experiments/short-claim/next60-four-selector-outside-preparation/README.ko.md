# 네 작업의 첫 실제 관측을 위한 실행 통제

네 요청과 입력 19개를 원본·대안 코드로 비교할 준비입니다. 예정된 후보 호출은 57회입니다. 이 폴더의 검사는 **가짜 프로세스의 상태와 저장된 메타데이터만** 다룹니다. 원본 실행과 학습 데이터 승인은 아직 수행하지 않았습니다.

실행 통제 코드는 한 번의 시작과 대기, 시간 초과·출력 상한 처리, 실패 결과 보존을 담당합니다. 중간 파일이 남아 있다는 이유만으로 실제 호출 수나 성공을 추정하지 않습니다. 코드·입력·바이너리의 체크섬과 별도 검토 근거를 연결한 뒤 실제 실행하도록 설계했습니다.

`preparation-v1/`은 작성자의 미실행 준비본입니다. `root-tested/source/`는 이 준비본을 별도 복사해 작성한 Go 코드만 정렬한 버전이며, 로컬 Go 1.27.1에서 가짜 검사 8개와 race·vet을 통과했습니다. CI는 두 운영체제에서 같은 독립 모듈을 검사합니다. 원본 패키지나 모델은 가져오지 않습니다. 실제 CI 결과는 해당 PR의 체크를 확인해야 합니다.

실제 관측 후에도 관측값과 기대값을 독립적으로 비교해야 새 요청이나 라벨로 인정합니다. 이 준비본 자체가 4개의 새 학습 요청, 57개의 실제 호출 또는 성능 개선을 뜻하지는 않습니다. 메모리 상한은 Go 힙에 대한 완화된 설정이며 전체 프로세스·GPU 메모리의 강제 상한이 아닙니다.

작성자의 봉인 기록과 로컬 검사 범위는 [HANDOFF](preparation-v1/HANDOFF.v1.json)와 [RESULT](root-tested/RESULT.v1.json)에 남겼습니다. 원본 코드·바이너리·개인 경로·실제 작업 프롬프트는 공개하지 않습니다.
