# U·모호함을 보존하는 Go 입력과 첫 메모리 개선

다음 5/8후보 코호트용 입력과 기존 학습 변환기 연결을 Go로 추가했습니다. [사용법·wire 계약](../../../pkg/shortclaimdata/COHORT.ko.md)을 먼저 보세요. 기존 Reader·37개 라벨·저장 비교·학습기는 바꾸지 않았습니다. **새 실제 코호트 관측·라벨·학습은0회**입니다.

미확인 U는 null로 보존하고, 모호한 요청의 알려진 T/F도 유지합니다. 부분 U·모호함·calibration·사용 행0인 부모는 전체 감사에 남기고 학습 변환에서 제외합니다. 모든 부모의 선언된 그룹/가족 역할과 공통 지문을 선택 전에 검사합니다. 선택된 완전 known 부모에서는 가중치0의 사실과 후보 전체를 유지합니다. 구조 검사와 opaque 지문 일치는 의미·라이선스·전체 계보나 학습 권한의 증명이 아닙니다.

Go1.27.1/darwin-arm64에서 같은 합성 fixture로 300ms씩3회 측정했습니다. 아래 시간은3회 중앙값이며, 단일 환경의 순차 측정입니다.

| 측정 구간 | 초기 시간 | 변경 후 시간 | 변경 후 Go 할당 |
|---|---:|---:|---:|
| 5후보 행 읽기 | 8.702μs | 8.756μs | 11,736 B /215회 |
| 8후보 행 읽기 | 11.503μs | 11.484μs | 15,250 B /291회 |

발견한 낭비는 감사 전용 경로의 acceptable 배열4,096 B·1회 할당이었습니다. 실제로 선택된 양성이 있을 때만 배열을 할당하도록 바꿔 세 번 모두0 B·0회를 확인했습니다. 전부 F인 부모도 배열이 필요 없습니다. 시간 변화 전체를 속도 향상이라고 주장하지 않습니다. 단일 환경의 측정 변동과 선택된 경로의 비용도 함께 남깁니다.

0 B는 이 함수 호출의 측정된 **힙 할당**입니다. 감사용 고정 배열·스택·호출자가 이미 보유한 문장·프로세스 RSS·native/GPU 메모리가0이라는 뜻이 아닙니다. 알려진13행 변환의 `project-owned-B`는13,477 B이며 `Project`의 반환 payload만 셉니다. 모델 추론·실제 작업량·토큰·금액 절감 측정은 아닙니다.

[초기 QA](LOCAL-QA.actual.public.v1.json)와 [변경 후 QA](LOCAL-QA.actual.public.v2.json)를 각각 보존합니다. 두 번 모두 해당 패키지 race 검사에서36개 최상위 테스트+114개 하위 테스트가 기본/`panicnil=1` 모드 각각 통과했고 실패·skip은0입니다. 새 테스트 함수는15개이며 위150개 기록에는 기존 검사가 포함됩니다. 전체 저장소 race·vet도 통과했습니다. 기존5개 소스/결과 파일은 HEAD와 바이트가 같고, 각 QA 수행 중 신규6파일 지문도 유지됐습니다. 검사는 합성 선언을 다루며 실제 Golden 표본 수를 늘리지 않습니다. 기존 저장소 테스트의 합성 Fit fixture와 새 코퍼스 학습을 구분합니다.

[독립 소스 검토](REVIEW.public.v1.json)는 실행 검증과 별도입니다. 역할 충돌 거절 테스트가 반환하는0카운터는 특징 함수 호출을 독립적으로 감시한 결과가 아닙니다. 선택 이전 guard 순서는 소스 검토에서 확인했습니다. 로컬 QA 기록의 CI 대기 상태는 작성 당시 상태이며 최종 CI/봇 병합은 Issue19에서 별도로 기록합니다.
