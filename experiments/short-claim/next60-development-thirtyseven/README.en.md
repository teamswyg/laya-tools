The13 new inputs and39 observations were compared against819 frozen predicates; a separate implementation matched every verdict. Union's cached cursor and JSON's per-object decoded-key policy passed every frozen condition. The other four candidates have concrete counterexamples. JSON Map's68 unknown predicates remain preserved. Combined with the previous35's post23/selected scope46, the linked scoped total is114, not an entire-history count. The39 pre-AFTER unknown SourcePanic diagnostics also remain in original evidence but are not added to Wanted predicate counts.

[ROOT-QUALIFICATION](ROOT-QUALIFICATION.actual.public.v1.json) records label authority; [ROOT-QUALIFIED-ROWS](ROOT-QUALIFIED-ROWS.v1.json) contains the two unit-weight rows. [MATERIALIZATION](MATERIALIZATION.actual.public.v1.json) and [post-close readback](ROOT-POST-CLOSE-READBACK.actual.public.v1.json) record actual Go generation and full Reader correspondence. The Reader does not assign semantic truth. Only request/candidate text enters features; labels, groups, sources and evidence stay separate.

37 is not the number of independent evaluation samples. Both requests retain existing groups79/83 and `development_train`. Union reuses catalog19's ID. JSON is related to an existing top-level JSONL envelope duplicate-key task; this request covers recursive per-object rejection before collapse and ordered prefixes. New independent groups, the new20→60 cohort and protected2400 evaluation additions are all zero. Candidate-position bias remains substantial, so this dataset alone demonstrates neither learning success nor cost savings.

Read [data/train.jsonl](data/train.jsonl) through the project Reader or reproduce the file and receipt with:

```sh
bash scripts/verify-next60-thirtyseven.sh
```

Go1.27.1 is required. Temporary files are generated from previous35 and pinned qualified rows, then checked byte-for-byte and against all Reader input/supervision/metadata values. Original tasks and models are not rerun. Passing these checks does not automatically authorize a new Fit or protected evaluation.

The HF public release remains [the pinned35-row version](https://huggingface.co/datasets/JooYoon/riidolaya-shortclaim-next60-development/tree/next60-35-finite-v1). The37-row successor is prepared for a separate version and complete public-file readback after new CI passes. Original implementations, executables, raw journals, host paths and model bodies are not added to GitHub. Publication covers owned requests, short captions and primitive labels; it expands neither upstream implementation licensing nor source independence.
