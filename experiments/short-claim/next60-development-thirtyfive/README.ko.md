# 35개 개발 요청: 작은 모델의 검증 순서 제안을 위한 자료

35개 요청과 후보 설명, 후보 라벨102개(양성35·음성67)를 담은 개발 자료입니다. 기존33행은 바이트 그대로 보존했고, Root가 고정 관측을 검토해 채택한 GJSON 두 요청을 추가했습니다. 실제 Go 생성1회가 exit0으로 끝났으며, 프로젝트 Reader가 35행의 입력·정답·메타데이터 전체를 대조했습니다.

목표는 작은 claim/hint 모델이 요청과 짧은 후보 설명을 읽고 검증할 후보의 순서를 제안하는 것입니다. 그 신호를 에이전트나 사람이 선택적으로 활용하고, 실제 결정·생성·실행에는 별도 검증을 붙일 수 있습니다. 이 자료만으로 모델의 정확도, 절감 효과 또는 낮은 메모리 추론을 입증하지는 않습니다. 이번 추가 작업의 새 Fit·모델 실행은0입니다.

| 항목 | 확인된 수치 |
| --- | ---: |
| 개발 요청 / 후보 라벨 | 35 / 102 |
| 양성 / 음성 | 35 / 67 |
| 고정 입력 | 171 |
| 원래 저장 증거의 전체 후보 관측 / 선택 후보 관측 | 509 / 500 |
| 양성 후보 위치0·1·2별 요청 수 | 5 · 28 · 2 |

새 두 요청은 비어 있지 않은 물리적 줄마다 완전한 JSON 값 하나를 검증하고, 앞선 콜백과 중단을 보존하는 작업 및 잘못된 UTF-8을 목적 버퍼에 쓰기 전에 거부하는 작업입니다. 고정 입력11개, 후보6개, 후보 관측33개를 바탕으로 라벨6개(+2·−4)를 추가했습니다. 저장된 판단309개는 참255·불일치18·미확인36입니다. 입력·관측·판단 수를 학습행이나 가중치로 늘리지 않습니다. 기존 원본 API는 다른 계약을 제공하므로 이 요청과의 불일치가 라이브러리 버그라는 뜻은 아닙니다.

미확인36개는 이전33 자료의 post23 범위10개와 함께 scoped46개로 남습니다. 전체 역사 미확인 수는 주장하지 않습니다. 이전에 제외한 OriginalInt의 null 라벨·가중치 정보도 보존했습니다. 알려진 반례가 있는 음성 후보는 다른 조건의 미확인 항목을 함께 남길 수 있으며, 미확인만 있는 후보를 음성으로 바꾸지 않습니다.

[data/train.jsonl](data/train.jsonl)을 읽고 [MATERIALIZATION.v1.json](MATERIALIZATION.v1.json)의 생성·대조 기록과 [Root 채택 v2](qualification/ROOT-QUALIFICATION.actual.public.v2.json)를 함께 확인하세요. Reader는 행마다1회, 총35회 시도·반환·전체 값 일치를 기록했고, Prepared 정규화 대조용 추가 ValidateInput35회를 별도로 기록했습니다. 설정과 Root SHA를 확인한 후 독점 예약한 파일에 저장했으며 이전33행 prefix가 일치합니다. 첫 저장 메타데이터 검사에서 잘못 추정한 필드명으로 실패한 기록은 남겼고, 기존 파일을 다시 확인해 정정했습니다. Go 생성이나 원본 관측을 재실행한 것은 아닙니다.

프로젝트 Go Reader의 `.Input()`은 요청·후보 입력, `.Supervision()`은 라벨·단위 가중치, `.Metadata()`는 원천·역할·유한 범위를 돌려줍니다. 향후 특징에는 요청과 후보 설명 텍스트만 사용하고 메타데이터·정답·관측 증거를 넣지 않습니다. [35행 검증 스크립트](../../../scripts/verify-next60-thirtyfive.sh)는 저장된 관측의 전체 조건과 35행의 값·바이트를 재현합니다. 원본 작업 실행이나 모델 학습은 하지 않으며, CI 결과는 별도 게시 기록에서 확인하세요.

현재 HF와 Wiki 공개판은33요청입니다. [HF33 고정 버전](https://huggingface.co/datasets/JooYoon/riidolaya-shortclaim-next60-development/tree/next60-33-finite-v1)은 유지되며 HF35는 CI와 별도 공개 절차를 기다립니다. 두 요청은 기존 GJSON group83의 development_train 역할을 이어받아 원천 독립성을 늘리지 않습니다. 후보 위치 편향과 문체 효과를 분리할 비교 기준을 앞으로 관측 전에 정해야 합니다. 약60개 준비 목표가 자동 Fit 허가는 아니며, 최종 주장에는 도메인별 보호2400 평가와5% 필요효용 기준이 별도로 남습니다. 원천별 권리 범위를 넓히는 문서도 아닙니다.
