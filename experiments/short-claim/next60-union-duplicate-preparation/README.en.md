# Small Go observer for the next cases

This bundle prepares riidolaya claim-model experiments. A tiny model may suggest candidates; training evidence still needs a record of what the original code actually did. Unknown facts remain unknown. Passing this observer does not qualify a label or authorize training.

Current validation uses authored synthetic inputs and fault injection. No new original worker, model or corpus Fit ran. The existing 35 development requests and 35 compressed records are different counts. Protected 2,400/domain evaluation and a 5% reduction in whole verification work remain pending.

| Component | Verified now | Pending |
|---|---|---|
| frame | 39-row schedule, fixed arrays/nested spans, ACK before thunk, no retry of uncertain effects; 14 controls | Original ABI and per-case call binding |
| durable | Independent order/counters; write→file Sync→parent Sync→ACK; separate durable/ACK prefixes; 6 controls | Actual file reservation/Sync, process exit and result correspondence |
| artifact-seal | Content/inode/size/mode/mtime drift and link rejection; 6 controls, Darwin/Linux vet | Compiler/build identity, rights and execution admission |

With Go1.27.1 on Linux/macOS, run the CI-equivalent synthetic checks from the repository root. The script assembles public module templates in an owned temporary directory and removes only that directory afterward. It downloads or executes no original worker or model.

```sh
bash scripts/verify-next60-union-preparation.sh
```

AFTER normal/panic facts must be non-null and exclusive. Interrupted write/ACK transport fails even under nil-panic compatibility. History retains the two initial source findings and initial passing controls; corrected copies and nonauthor reviews are separate evidence.

Limits: 2,048B including LF per line, 640 frames. An intentionally invalid DTO superset overestimates every valid field width and still encodes to 1,505B. This bounds wire bytes, not process memory or inference speed. One owner loop and contiguous fixed arrays need no maps or locks. Small span records are consumed together; any SIMD/SoA improvement needs separate measurements.

Four completed duplicate records were archived only after actual on-disk restore/hash/mode verification; saved-only peer review passed. Conservative reclaim: 666,800B new and 11,902,227B cumulative. Public canonical records remain. A compiler-only harness and disposable executables are proposals; they grant no exclusion to existing binaries and do not reset the resource cap.

A future original worker requires frozen fixtures/Wants, per-case coverage, source/rights/compiler closure, actual executable pins, genuine EOF plus process exit/result correspondence and fresh resource admission. Native/GPU inference and training each require their own actual evidence. Existing Laya CI inference passed separately; GPU execution is unverified.
