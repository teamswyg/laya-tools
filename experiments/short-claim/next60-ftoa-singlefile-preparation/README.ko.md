# Precise Ftoa: 원본 한 파일 준비

기존 개발용 요청 하나를 빌드·실행 없이 준비합니다. 원본 ftoa.go 전체986바이트와 MIT 고지1136바이트를 비공개 원본 패키지에 그대로 보존했습니다. 전체 humanize 패키지나 컴파일러·의존성 closure를 완성한 것이 아닙니다. 공개 자료에는 직접 작성한 소스 텍스트·입력·사실·계획만 있으며 원본 본문·실행파일·모델·비공개 경로는 복사하지 않습니다.

후보 세 개를 구분합니다. 원본 FtoaWithDigits는 먼저 소수6자리로 표시한 다음 잘라내며 문자열만 반환합니다. 없는 오류 반환채널을 unavailable로 기록하고 nil을 발명하지 않습니다. 직접 작성한 FtoaPrecise(float64,int)(string,error)는 원래 표현값을 지정 정밀도로 표시합니다. 독립 작성한 FlawedDoubleRound는6자리 반올림→그 중간값 파싱→다시 반올림하는 실패 후보입니다. 이 별도 준비에서만 기존 초안의 실패 후보 설명을 변경했으며 원 초안은 보존합니다.

독립 검증 계산은 IEEE 비트를 정수 유효숫자×2의 지수로 풀고, 정확한 유리수에10^digits를 곱한 뒤 몫·나머지로 짝수 반올림을 구현합니다. 기대값 생성에 FormatFloat·ParseFloat·후보 함수를 사용하지 않습니다. 정확한9/8·11/8은 서로 다른 절반 경계를, 올림과9자리 사례는 다른 동작을 확인합니다. 소수 문자열은 같은 리터럴의 고정된 typed float64 Go 상수를 선택합니다. 실제 비트와 컴파일러 상수 변환 증거는 별도로 허용된 최초 실행에서 남겨야 합니다. 음수0와 무한대는 명시합니다. 검증 계산과 후보는 아직 실행하지 않았습니다.
