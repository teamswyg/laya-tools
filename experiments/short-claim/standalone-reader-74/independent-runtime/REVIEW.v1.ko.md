# Reader74 저장 기록 독립 검토

저장된 실행 기록 정합성 검사를 통과했다. 원본 숫자 배열을 다시 읽거나 reader·codec·관찰기·모델을 재실행한 결과가 아니다. 검토자 `semantic_review60_prep`는 reader/controller 작성자와 다르지만, 이전 codec와 사전 검토를 보았으므로 전체 과정에 대한 맹검은 아니다. AI 에이전트가 자료를 읽고 검토했다.

원래 계획에서 `Frozen: false`를 `true`로 바꾼 한 토큰 외에는 바이트 변화가 없다. 기존 독립 사전 검토 영수증도 그대로다. controller의 최종/부분 기록, 각 자식의 최종/부분 기록이 각각 바이트까지 같다. 저장된 기록에는 JSON·compact 각각 시작 1회, 재시도 0회, 종료코드 0, 시간초과 없음, `Wait` 반환이 있다. JSON 사전 검사·실체화는 각각 1/1회, compact 읽기·Decode는 각각 1/1회, 검증은 각 1/1회다. 상태와 두 성공 필드까지 확인했으며 종료코드만으로 성공을 판단하지 않았다.

4개 데이터셋의 6개 열, 총 24개 열에서 길이·nil 여부·해시가 양쪽 기록에 모두 일치한다. 행은 91/45/73/44, 희소 항목은 67,104/37,975/37,916/37,657개다. 이번 스냅샷의 24개 열은 모두 nil이 아니다. 원본 JSON·메타데이터·전체 비트 해시도 같다. 저장된 길이로 계산한 숫자 배열 1,814,648B와 메타데이터 163,758B의 합은 기록된 소유 payload 1,978,406B와 일치하며 64MiB 이하다. 원래 projection의 payload와는 계산 범위가 다르다.

| 저장된 측정값 | JSON | compact |
| --- | ---: | ---: |
| 전체 자식 OS real/user/sys(초) | 0.49 / 0.08 / 0.01 | 0.05 / 0.01 / 0.00 |
| controller 자식 wall(초) | 0.50100075 | 0.058869916 |
| 최대 RSS(B) | 19,120,128 | 19,300,352 |
| peak footprint(B) | 16,269,840 | 15,745,528 |
| 종료 시 Go HeapAlloc(B) | 4,660,664 | 4,765,512 |
| 누적 Go TotalAlloc(B) | 44,840,120 | 21,608,800 |

위 OS 값은 저장된 원시 시간 로그와 일치한다. compact의 누적 할당은 이번 실행에서 작았지만 최대 RSS는 180,224B, 종료 시 Go heap은 104,848B 더 크다. 따라서 RAM 절감이 입증됐다고 말할 수 없다. `0.00`은 표시 정밀도에서 반올림된 시간이며 CPU 사용이 없었다는 뜻이 아니다.

controller가 파일 해시를 미리 읽어 캐시가 따뜻해진 상태에서 JSON 다음 compact를 고정 순서로 각 1회 실행했다. OS 측정은 파일·소스 검증, 읽기, 배열 검증, 해시 계산, 결과 저장을 포함하는 전체 자식 수명이다. 더 짧은 시간이 관찰됐지만 형식 자체의 인과적 10배 가속, cold I/O, 대규모 데이터, 실제 서빙 성능을 입증하지 않는다. HeapAlloc은 마지막 heap 관측, TotalAlloc은 누적 할당이며 peak heap이나 RSS가 아니다. Go soft 256MiB와 소유 payload 64MiB도 강제 OS RSS 제한이 아니다.

검토는 표준 Go 저장 기록 도우미 1회/실패 0회로 184개 조건과 16개 파일 핀을 대조했다. 전체 배열 해시의 재계산은 하지 않았다. 해시 동등성 해석은 기존 소스 검토에 근거하며, 독립적인 두 번째 수치 배열 검사로 표현하지 않는다. 최소 환경 키는 root의 호출 기록에 선언되어 있다. 이 검토자가 실제 과거 프로세스 환경·개수를 별도 관찰한 것은 아니다.

새 원본 API·입력 배열 읽기·reader/parser/codec 실행·테스트·Features·Project·Fit·역할·라벨·모델·HF 작업은 모두 0회다. 학습 준비·성능 승인·보호된 2400 final 완료는 계속 false다. 모델/유료 호출 0은 별도의 추론/API 실행을 하지 않았다는 뜻이며, 이번 AI 보조 협업 비용이 0이라는 뜻은 아니다.
