The new JSON path does not call old ImportJSON. Pass1 checks numeric token types/ranges/finiteness, every column count/null flag and CSR offsets/row shapes. It validates the aggregate metadata+typed-array payload across all four datasets against64MiB before pass2 allocates CSR arrays. Pass2 must preserve source SHA, shapes and metadata. Objects reject exact duplicate keys after escape decoding; small typed controls additionally reject lowercase-key duplicates. Compact uses the unchanged Decode with exact source pins. Both paths' Summarize applies the same structure/finite checks and strict canonical-metadata byte equality.

Digests cover all six columns of all four datasets, including dataset/column position, count, nil flag and ordered int64/uint16/FP64 bits. They retain distinctions such as null/empty, -0 and ordering. Full Summary equality also includes source SHA, exact metadata SHA/length, owned payload and each column SHA. This is hash-based comparison, not a repeat of the prior codec roundtrip. No actual input digest was computed here.

The controller verifies source/binary/input pins before changing only Frozen false→true. It creates a fresh exclusive attempt, frozen plan, fsynced controller prefix and each child intent/directory before Start. Exactly one JSON then one compact child are planned, with no automatic retry. Each60-second timer connects process-group SIGKILL to Wait. Failures/incomplete outputs retain validated prefixes or raw file refs plus exit/timeout/overflow status. Workers fsync stage intents and returned prefixes. An interrupted prefix is the last durable record, not complete proof of actual function entries.

One operational distinction must remain explicit: after recording child failure or digest mismatch as `completed_two_children_failed_or_mismatched_no_approval`, the controller may still exit0. Exit status can mean **record persisted**; comparison success requires `BothCompleted && ArrayAndMetadataDigestsEqual` and the final state. This is not a blocker when root inspects those fields, but shell exit0 alone must not establish successful equivalence.
