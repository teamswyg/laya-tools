# Catalog9 저장 결과의 유한 비교

9개 작업의 고정 입력 46개에 대해 원본, 작성한 참조 후보, 작성한 오류 후보를 각각 비교했습니다. 비교 대상은 Root가 이미 저장한 138행입니다. 이 검토에서는 원래 작업 코드를 다시 실행하지 않았습니다.

결과는 입력별 만족 102행, 불만족 35행, 판단 불가 1행입니다. Wanted의 개별 조건 1,347개는 알려진 일치 1,246개, 알려진 불일치 72개, 판단 불가 29개입니다. 9개 참조 후보는 각 작업의 모든 고정 입력과 모든 Wanted 조건을 충족했습니다. 원본 9개와 오류 후보 9개에는 각각 알려진 반례가 있습니다.

아래 숫자는 0부터 시작하는 입력 위치입니다. 참조 후보는 모두 만족하므로, 표에는 두 비교 후보의 실제 반례만 표시했습니다. 각 후보의 전체 입력별 결과와 판단 불가 위치는 [상세 비교](FINITE-COMPARISON.v1.json)에 보존했습니다.

| 작업 | 입력 수 | 원본 반례 위치 | 오류 후보 반례 위치 |
| --- | ---: | --- | --- |
| annotation-ownership | 5 | 0, 1, 2 | 1 |
| bounded-count | 6 | 1, 3, 4 | 3, 4 |
| single-assignment | 5 | 0, 1 | 1 |
| sensitive-default | 5 | 0, 1, 3 | 3 |
| deferred-function | 5 | 1, 2, 3 | 1, 2 |
| text-error-value | 5 | 0, 1 | 0, 1 |
| hooks-errors-is | 5 | 0, 3, 4 | 2 |
| remain-conflict | 5 | 0, 1, 4 | 1 |
| tag-precedence | 5 | 1 | 1 |

판단 불가 한 행은 annotation-ownership 작업의 원본 후보, 입력 위치 3입니다. 해당 버전에서 getter 관측 채널을 사용할 수 없어 9개 조건이 판단 불가이고, 나머지 8개는 알려진 일치입니다. 이를 실패로 바꾸지 않았습니다. 다른 행에서는 알려진 불일치와 판단 불가가 함께 존재할 수 있습니다. 그 경우 행은 불만족이지만 판단 불가 조건도 그대로 기록했습니다.

비교는 Wanted에 선언된 조건에 한정됩니다. 추가 Got 메타데이터는 무시하지만, 빈 객체와 `/maps/A`, `/maps/B`의 전체 키 집합은 비교합니다. 배열 순서, 필드 존재 여부, null, 빈 배열, 빈 객체를 구분합니다. 관측할 수 없다고 선언된 error/getter/flag-identity 채널은 판단 불가로 처리합니다. 실제로 알려진 값이나 타입이 다르면 불일치입니다. `message_observed=false` 및 `message=null`의 일치는 관측 메타데이터의 일치이며, 내부 Error 호출이 없었다는 증명은 아닙니다.

검토자는 후보·Wanted·observer의 작성자가 아닙니다. 다만 이전 소스 검토와 수정 의견을 알고 있었으므로 눈가림 검토는 아닙니다. 검토자가 작성한 표준 라이브러리 Go 비교기는 합성 제어 검사 후 봉인했고, Root가 그 소스를 독립적으로 읽어 구체적 차단 문제가 없음을 확인한 다음 실제 저장 결과를 한 번 비교했습니다. 합성 검사는 실제 후보나 모델의 성능 증거가 아닙니다.

비교기 실행은 1회, 종료 코드는 0, 표준 오류는 0바이트입니다. 입력 결과의 SHA-256은 `5b0634522473882a7823c33565d3db68a6f11efd28e2b3474a59f8d6d57bfb99`이고, 비교 보고서는 86,308바이트입니다. 원본 코드 import·init·API 실행, 원 worker 재실행, 모델 실행·학습, 보호 자료 읽기, 네트워크 작업은 이 비교에서 모두 0입니다.

Root는 별도의 원 worker 실행에 대해 RSS 8,388,608바이트와 경과 시간 1.509219167초를 보고했습니다. 이 수치는 worker 전체의 측정이며, 이 비교기가 측정한 값이나 모델·GPU 메모리 또는 모델 추론 속도가 아닙니다. 원본 startup·내부 호출 횟수는 알려지지 않아 null로 유지됩니다. 외부 프로세스·저널 증명은 Root의 별도 기록이며 이 비교기의 증명이 아닙니다.

이 기록은 고정된 46개 입력에서 후보가 Wanted를 만족하는지에 대한 증거입니다. 일반적인 파서 정확성, 모델 품질, 비용 절감, 라이선스 보증 또는 새 공개 CI 통과를 주장하지 않습니다. `labels_assigned=false`, `qualified=false`를 유지했습니다. 라벨·역할·학습 반영과 최종 유한 채택은 Root가 별도로 결정합니다. 열 번째 unknown-token-report 작업의 6개 입력은 이번 비교에 포함하지 않았습니다.
