# 실제 실행으로 확인한 9개 개발 작업

이 기록은 작은 주장 모델의 **학습 정답을 만들기 위한 코드 검사**입니다.
Laya 추론, GPU 실행, 모델 학습이나 비용 절감 실험 결과가 아닙니다.

고정한 공개 요청 9개에 입력 46개를 준비하고, 각 입력에서 원본·참조·오류
후보를 처음으로 실행했습니다. 138개 관측을 저장한 뒤 별도의 비교기로
실행 전에 고정한 Wanted와 대조했습니다. 원본을 다시 실행하거나 Wanted를
실행 결과에 맞춰 수정하지 않았습니다. 열 번째 unknown-token 요청은 보류입니다.

| 확인한 내용 | 결과 |
|---|---:|
| 실제 작업 / 입력 / 후보 관측 | 9 / 46 / 138 |
| 관측 전체 만족 / 알려진 불일치 / 판단 불가 | 102 / 35 / 1 |
| 비교 항목 참 / 거짓 / 판단 불가 | 1,246 / 72 / 29 |
| 모든 고정 조건을 만족한 참조 후보 | 9 |
| 알려진 반례가 있는 원본·오류 후보 | 18 |
| 최초 실행 / 재실행 / 패닉 | 1 / 0 / 0 |
| 검사 worker 최대 OS 메모리 | 8 MiB |
| 실행·기록·저장을 포함한 시간 | 약 1.51초 |

메모리는 macOS `/usr/bin/time -l`의 worker 최대 RSS입니다. Go 힙이나
GPU 메모리 측정값이 아닙니다. 899회는 검사 코드가 명시적으로 센 호출이며,
그중 오류 문자열 메서드 호출은 42회입니다. 라이브러리 내부 호출과 초기화
호출 횟수는 알 수 없습니다. 파일 동기화의 반환을 확인했지만 전원 장애에
대한 모든 저장장치 보장을 주장하지 않습니다.

**정답의 의미:** 참조 후보는 이 입력들에서 필요한 비교 항목이 모두 알려진
참일 때만 양성입니다. 음성은 알려진 반례가 하나 이상 있다는 뜻입니다.
모르는 항목을 거짓으로 바꾸지 않습니다. 원본의 일부 기능이 관측되지 않아도
다른 입력의 확실한 반례로 음성이 될 수 있습니다.

이 9개는 기존 pflag·mapstructure 계열을 재사용합니다. 새로운 소스 계열의
성능 검증으로 세지 않습니다. 모든 참조가 두 번째 후보라 위치 편향이 있으며,
설명 문체도 정답을 드러낼 수 있습니다. 후보 순서 변경과 단순 위치·키워드
기준을 다음 학습 평가에 함께 넣어야 합니다.

`evidence/`는 로컬 최초 실행에서 나온 공개 입력의 관측과 외부 검사 결과입니다.
`independent-semantic-review/`는 저장된 결과를 비교한 독립 검토입니다.
검토자는 원본·Wanted·후보 작성자가 아니지만 내용을 알고 검토했으므로
맹검이라고 부르지 않습니다. 최종 라벨 채택은 별도
[`next60-development-sixteen`](../next60-development-sixteen/) 기록에서 합니다.

`source/`에는 자체 작성한 Go 코드만 `.go.txt`로 보관합니다. CI는 외부 검사기와
비교기의 **합성 오류 검사**, 저장된 공개 관측의 재비교, 데이터 검증을 합니다.
CI가 이 원본 worker를 실행하거나 138개 실제 관측을 새로 만든다고 해석하면
안 됩니다. 원본 라이브러리 몸체·바이너리·원시 journal·호스트 경로와 설정은
게시하지 않습니다. 정확한 원본 revision과 전체 라이선스 고지는
`evidence/ROOT-RIGHTS.frozen.v1.json`과 `notices/`에 있습니다.
