# 고정 학습량으로 주장 의미를 비교하는 Go 실험

개발 댓글의 답변 요청·진행·완료 보고를 적은 비용으로 제안하는 것이 목표입니다. 보고는 글쓴이의 주장이고 실제 작업 완료의 증거가 아닙니다. 이 실험은 3진 압축과 분리해, 일부 새 의미 대조 자료가 작은 실수 분류기의 일반화를 개선하는지 한 번 시험합니다.

## 고정한 조건

원래 실수 부모에서 새 AdamW 누적값·업데이트 번호로 40epoch를 한 번 추가 학습합니다. batch32·학습률0.001·weight decay0.01·seed1729·온도1·특징2048개·확신도0.9·마진0.05를 유지합니다. 원래2120회에 새2120회를 더해 총4240회입니다. 이전에 고정한 실수 추가 학습 모델과 비교하며 epoch·seed·문턱 탐색이나 추가 재시도를 하지 않습니다.

자료는 원래 합성 학습1440행을 유지하고 새 원본 대조240행을 넣은1680행/840언어쌍 가족/280그룹입니다. 같은 상황의 번역·표현 변화·의미 대조는 같은 그룹으로 관리합니다. 주체·시점·인용·범위가 의미를 어떻게 바꾸는지 다루며, 사실 미확인을 무조건 semantic unknown으로 만들지 않습니다.

새 평가360행/180가족/60그룹은 학습 작성자와 분리해 모델 결과 전에 준비합니다. 대조240행/40그룹과 일반120행/20그룹을2:1로 집계합니다. 일반 층의 클래스 비율은 강제하지 않습니다. 독립 AI 검토·이견 판정은 사람 골든셋이나 제품 성능 증거가 아닙니다. 기존 노출 검증 및 원래/기존 보정·시험 자료는 이번 학습·선택에 사용하지 않습니다.

## 검증과 사용

`cmd/riido-statehint-claims-contrast-study`는 Go1.27.1의 유지보수용 실행기입니다. 원래 부모·고정 대조군·학습·평가·층별 메타데이터·작성자 집계 영수증에 파일 SHA를 명시합니다. 실행기는 새 자료의1440/240 출처를 외부 검토 영수증으로 확인하는 경로와 함께 사용해야 합니다. 전체 행/가족/그룹과 실제 평가 지지 수는 다시 확인하지만, 새 자료의 원본성·사람 정답을 스스로 증명하지는 않습니다.

`--check`는 모델 컨테이너·학습·원문 없는 메타데이터를 검사하고 평가 파일은 존재·크기·파일 식별만 확인합니다. 평가 본문을 열거나 해시하지 않으며 모델 Load·추론·Fit·출력 생성도 하지 않습니다. 동일 경로나 hard link로 평가를 다른 입력에 지정하는 경우 읽기 전에 거부합니다.

실제 `--out .cache/statehint-claims-contrast-study/새이름`은 딱 한 번 Fit한 후보를 먼저 저장한 뒤 평가 본문을 읽고 대조군을 Load합니다. 평가가 깨졌거나 나중 단계가 실패해도 소비한 Fit과 후보를 기록하고 같은 출력 폴더로 재시도하지 않습니다. 이것은 호출/출력별 보호이며 프로젝트 연구 장부가 전체 한 번 예산을 별도로 관리합니다. 임의 새 폴더로 반복해 한 번 제한을 우회해서는 안 됩니다.

평균 CE 차이는 후보-고정 대조군입니다. 각 행의 세 항목 CE를 평균한 뒤 KO/EN을 함께 포함한6행 그룹을 재표집합니다.40/20그룹의 층별 paired bootstrap은10000회·seed1729,95% percentile구간의 `q*(N-1)` 선형보간을 고정합니다. 연구 진행 조건은 구간 상한<0, 양 언어 unknown-target CE 감소, 모든 언어/항목의 긍정 오탐 증가 없음입니다. false와 unknown 참조에 대한 true 제안 모두 오탐으로 계산합니다. 연구 진행과 운영 적격은 구분하며 운영 적격·선택·확률 보정·앱 쓰기는 실행기에서 false/0으로 유지합니다.

출력은 원문·ID·행별 점수 없이 집계합니다. 모델·보고서·선택적 CPU pprof는0700폴더/0600파일에 저장합니다. Go힙과 전체 프로세스 RSS는 다르므로 외부 측정을 함께 기록합니다. 입력·metadata와 출력의 경로는 local 상대 경로로 제한하고 symlink·드리프트·크기 초과를 거부합니다. 자료 작성·블라인드 검토·외부 분할 감사 및 봉인을 마친 뒤에만 실제 실행합니다.

실행 옵션과 범위는 `go run ./cmd/riido-statehint-claims-contrast-study --help`로 확인합니다. [고정 계획](https://github.com/teamswyg/laya-tools/issues/155#issuecomment-6030919673)과 [이전3진 실제 결과](https://github.com/teamswyg/laya-tools/issues/155#issuecomment-6031062084)는 별도 기록입니다. 가중치·평가 원문·원시 프로파일은 Git에 올리지 않습니다.
