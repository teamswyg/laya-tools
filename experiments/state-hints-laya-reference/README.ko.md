# 노출된 개발 검증 자료의 동결 Laya 참고 실행

오프라인 유지보수 실험이며 Python을 제품 런타임에 추가하거나 새로 학습하지
않습니다. 캐시된 영어 Laya 기본 모델
`55cf4c4ebb4ebe31b2550e8bdf3bd21b99753851`과 이미 게시한v0.1 마지막 선형 계층
교체 파일을 비교합니다.842,609,210바이트 기본 모델과4,252바이트 delta를 변경하지
않습니다. 다운로드·가중치 갱신·증류·보정·선택·승격·앱 상태 변경은 없습니다.

기존V1 지시문과8선택지를 그대로 사용합니다. 특히 인용·가정 문장의 unclear
정의가 새V4 현재 단위·범위 규칙과 다릅니다. 정의 간 이전을 관측하는 참고값이며
적격 teacher나 구조 차이만 분리한 비교가 아닙니다. 영어 모델의 한국어 능력도
적격으로 주장하지 않습니다.

이미 결과가 노출된 validation120가족240한영 행만 고정SHA와 쌍·클래스 검사로
받습니다. train·calibration·최종test·전체manifest·실제 비공개 태스크 입력은 없습니다.
모델 작업자에게는 문장만 전달하며 기대 라벨이나 범위 주석은 forward에 영향을
주지 않습니다. 예측과 특징은 비공개로 유지합니다. 직접 만든 stub테스트는 실제
참고 모델을 호출하지 않았습니다.

```sh
# 기존 Laya0.3.21 / Torch2.14.0 유지보수 환경 사용
python experiments/state-hints-laya-reference/evaluate_reference.py \
  --base BASE_DIR --delta DELTA.safetensors \
  --validation EXPOSED_VALIDATION.jsonl \
  --plan PLAN.json --plan-sha256 PLAN_SHA --check
```

`--check`는 기본·delta·설정·tokenizer·자료·계획의 정확한 핀과 입력 상한을 확인합니다.
Torch/Laya를 import하거나 모델을 호출하거나 결과 파일을 쓰지 않습니다.
별도 승인된 참고 실행은 `--check`대신
`--run --out .cache/statehint-laya-reference/NEW-RUN`을 사용합니다. MPS가 필수이고
CPU fallback과 네트워크 로딩은 금지합니다. 다른 partition을 열고 가중치를 학습할
수 있는 이전 trainer를 import하거나 실행하지 않습니다.

작업자1개가 행별로 동결 모델을1회만 실행하여 마지막 선형 계층 입력의
8×1,024차원FP32벡터를 받습니다. encoder호출은 최대240회입니다. 같은 벡터로
기본·delta점수를 구하며 기본 native logit재구성의 절대 오차는.001이하여야 합니다.
저장한 점수는 CPU의 마지막 선형 계층 계산이고, 전체 기본 모델의 native MPS logit은
일치 확인에만 사용합니다. delta를 얻으려고 기본 가중치를 교체하지 않습니다. 캡처한 벡터를 CPU에서 계산하며
두 번째 기본 모델이나 encoder재시도는 없습니다.

기본 모델은 고정 설정의 기존 `choice:6-10`온도1.0000158548355103,
delta는 이전에 고정한0.65를 사용하고 호출 전에 기록합니다. raw온도 진단·탐색·새
보정은 없습니다. 본문 없는 `scores.json`은8logit/확률,행ID·언어·문장SHA와
기본/delta출처를 담습니다. 참고 모델의 학습 step은 unknown/null로 유지하며
Go optimizer이력으로 꾸미지 않습니다. 별도 Go참고 명령은.9/.05의 P/C/Q가족·언어
관측만 계산하고 이를 적격 Go상태 분류기처럼 표현하지 않습니다.

새 결과 폴더는0700,파일은0600입니다. `features.f32le`는 정확히7,864,320바이트이며
입력 행·고정 선택지·특징 순서입니다. 메타데이터에 해시·형식을 기록하고 전체 출력은
16MiB이하입니다. 기본 모델 복사·새 가중치·원문 내보내기는 없습니다. 프로세스
최대RSS5GiB이하,시스템 가용성20%이상,MPS allocator비율.25를 적용하고 driver할당도
해당 비율로 표본 확인합니다. native forward시간과 전체 참고 실행 시간을 구분합니다.
MPS표본은 순간 최고값을 놓칠 수 있고 통합 메모리의 RSS/MPS는 겹치므로 합산하지
않습니다. 실패는 `FAILED.json`과 부분 특징을 비공개로 남기며 성공 적격으로 보고하거나
자동 재시도하지 않습니다.

모델 의존성 없이 직접 만든 산술 stub테스트를 실행합니다.

```sh
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover \
  -s experiments/state-hints-laya-reference -p 'test_*.py'
```

1회 특징 캡처·두 head점수·전체 특징 바이트·라벨/주석 분리·유한 점수·재구성/절단
실패·고정 계획 위반·핀/입력 상한·비공개 독점 출력을 검사합니다. 실제 사전학습 모델의
정확도나 MPS실행을 증명하지 않는 파이프라인 테스트입니다. 실제 실행에는 ROOT의
별도 자원 확인과 실행이 필요합니다. 모델·코드의 Apache-2.0라이선스,Go제품 런타임,
기존 실험 파일을 유지합니다.

## 실제 동결 참고 run01

ROOT가 이미 결과가 노출된120가족240행43lineage 검증 자료에서 Torch MPS/FP32
작업자1개를 실행했습니다. 동결 기본 모델의 forward240회에서 얻은 동일한 특징으로
두 CPU 마지막 선형 계층의 저장 점수를 계산했습니다.

| 참고 모델 | 기존 온도 | 전체 정답 /240 | KO정답 /120 | EN정답 /120 | EN gated P/C/Q제안 (모두 정답) |
| --- | ---: | ---: | ---: | ---: | --- |
| 사전학습 기본 |1.0000158548355103|89|16|73|8/4/0|
| 게시된 v0.1 delta |0.65|88|16|72|7/4/0|

한국어의 P/C/Q제안은0개이므로 해당 정밀도는 정의되지 않습니다. 영어 완료는
각 모델에서15가족 중4가족(26.7%포괄률),선언 lineage3개이며 제안4/4는 정답입니다.
영어 질문도 제안0개여서 정밀도가 미정입니다. 적격성은 평가하지 않았고 학습 step은
unknown/null입니다. 선택·적격 판정·승격·새Fit·calibration·최종test·실제 비공개
태스크 호출은 없습니다.8분류NLL은1.738268→1.616183이지만 기존 온도가 달라
head개선만 분리한 결과가 아닙니다. 사용 가능한 적격 teacher를 입증하지 못했습니다.

전체 프로세스 관측1회는24.24초(CPU user4.76초/system6.78초),최대RSS
2,887,172,096바이트(2.69GiB)였습니다. 로딩·자원 확인·특징 추출을 포함한 작업자
시간은23.442초입니다. 동기화한 native 전체 기본 모델 forward는 합계13.229초,
평균55.12ms,범위33.77–401.02ms입니다. 서로 다른 시간 범위이며 이식 가능한 제품
지연이나 통제된 속도 개선으로 해석하지 않습니다.

MPS driver/할당 표본의 최대값은2,166,046,720 /1,688,613,632바이트,시스템 가용성의
최소값은51%였습니다. MPS표본은 순간 최고값을 놓칠 수 있고 통합 메모리의RSS와
겹치므로 합산하지 않습니다. 정확히7,864,320바이트인 특징 캐시를 포함한 전체
producer출력은8,300,158바이트로16MiB이하입니다. 입력/선택지 절단은 없었고
151–433토큰,최대 native 재구성 오차1.9073486328125e-6으로 기존.001기준 안입니다.
Go제품 런타임과 기존 가중치는 그대로입니다. 후속 모델 호출이나 지도 probe는
별도 사전 고정 실험이 필요하며 이 참고값으로 teacher라벨 증류를 정당화하지 않습니다.
