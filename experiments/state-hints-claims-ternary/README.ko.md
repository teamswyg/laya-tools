# 작은 주장 모델의 3진 가중치 실험

이 실험은 개발 댓글의 답변 요청·진행·완료 주장 모델을 더 작게 저장하고, 작은 메모리로 반복 추론할 수 있는지 확인합니다. 원래 float32 연구 모델은 그대로 유지합니다. 작은 파일이 의미 품질이나 실제 처리 속도를 보증하지는 않습니다.

## 무엇을 3진으로 바꾸나

출력의 있음·없음·불명확과 별개로 **가중치**를 `-1, 0, +1`로 바꿉니다. 출력 세 항목은 여전히 각각 세 범주의 확률입니다. 한 항목의 가중치 행렬마다 평균 절댓값에서 구한 배율 하나를 저장합니다. 실제 계산에는 `배율 × 3진 가중치`를 사용하며 입력 특징·편향·배율은 실수입니다. 문장을 생성하는 BitNet LLM이나 W1.58/A8 전체 구현이라고 부르지 않습니다.

다섯 3진 값을 한 바이트에 넣습니다. `3^5=243`이므로 256개 바이트 값 안에 들어갑니다. 가중치 저장은 완전한 묶음에서 **값당 1.6비트**이며, 이론적인 `log2(3)≈1.585`와 다릅니다. 18,432개 가중치는 3,687바이트이고 편향·배율·형식 정보·검사합까지 포함한 RQT 형식은 4,023바이트입니다. 파일 크기·추론 모델의 실제 구조 크기·Go힙·전체 프로세스 RSS를 따로 측정합니다.

추론에서는 압축된 가중치에서 현재 사용한 특징의 값만 꺼냅니다. 큰 float32 행렬로 풀어 저장하지 않습니다. 모델은 읽기 전용이고 작업 공간은 호출자가 소유하며 전역 캐시나 추론 락을 두지 않습니다. 그래도 문자·단어 특징 추출과 실수 계산은 남으므로 CPU 가속은 실제 관측 전까지 주장하지 않습니다.

## 비교하는 네 조건

1. 게시된 float32 모델을 그대로 사용합니다.
2. 같은 모델에서 실수 순전파로 40회 더 학습하는 비교 조건을 둡니다. QAT와 초기값·자료·순서·업데이트 횟수를 맞춥니다.
3. 같은 모델 가중치를 한 번 3진으로 변환합니다(PTQ). 추가 학습은 없습니다.
4. 원래 float32 가중치에서 시작해 3진 순전파를 쓰며 40회 추가 학습합니다(QAT). optimizer의 누적값과 업데이트 번호는 새로 시작하고, 원래 2,120회 학습 이력은 별도로 보존합니다.

QAT 조건에서는 순전파 값이 3진이어도 학습 중에는 원래 실수 가중치를 유지합니다. 반올림의 실제 미분 대신 gradient를 그대로 전달하는 identity STE를 고정한 연구 조건입니다. 이것이 참 미분이나 공식 BitNet 학습법과 같다고 주장하지 않습니다. AdamW 학습률0.001·weight decay0.01·batch32·seed1729·40epoch·온도1의 한 조건만 사용합니다. 가중치 decay와 편향의 처리 방식은 원래 Go 구현을 유지합니다. 추가 학습만으로 좋아진 결과를 3진화의 효과라고 부르지 않도록 실수 추가 학습 조건을 모델 실행 전에 포함했습니다.

수치 규칙은 항목별 `s=max(mean(abs(W)),1e-5)`, `t=clip(RoundToEven(W/s),-1,1)`입니다. 정확히 ±0.5이면 0이 됩니다. float64 평균을 계산한 뒤 float32 배율을 저장하는 독립 Go 구현으로, PyTorch 변환 결과의 비트 일치를 주장하지 않습니다.

## 근거와 사용

[BitNet b1.58 원논문](https://arxiv.org/html/2402.17764v1#S2)의 평균 절댓값 양자화 아이디어와 [Microsoft의 고정 변환 코드](https://github.com/microsoft/BitNet/blob/85a507c67dd2e361f94152c1e8babff2cb4e7daf/utils/convert-hf-to-gguf-bitnet.py#L1055-L1060)를 참고합니다. [identity STE 논문](https://arxiv.org/pdf/1308.3432)과 [clipped STE 논문](https://arxiv.org/pdf/1602.02830)은 서로 다른 조건이며 이번 실험은 identity를 선택합니다. 공식 코드의 MIT 구현을 복사하지 않고 자체 Apache-2.0 코드·자료·가중치를 사용합니다. [laya.tools](https://laya.tools/)의 선행 프로젝트에도 감사드립니다.

Go1.27.1에서 `riidolaya claims --model MODEL.rqt --jsonl`로 명시적인 연구 모델을 읽습니다. 기존 `.rsc` 모델도 같은 명령을 사용합니다. RQT와 RSC는 별도 형식이며 변환 단계·부모 SHA·상속 학습 횟수·추가 optimizer 횟수를 결과에 기록합니다. 자동 등록·다운로드·앱 상태 쓰기는 없습니다. 모든 출력은 연구 미리보기입니다.

기존 확신도0.9·마진0.05는 유지합니다. 이미 노출된 검증240행의 비교는 진단이며 새로운 시험·모델 선택·보정의 증거로 사용하지 않습니다. 실제 업무 원문은 학습·게시하지 않고 원래 및 새 보정/시험 봉인도 유지합니다. 원시 프로파일은 로컬에 둡니다. 가중치 모델은 Git에 넣지 않고, 허용된 연구 패키지만 HF의 불변 버전으로 게시합니다.
