# 학습 자료부터 점검하는 PDCA

이번 단계는 새 모델을 학습하기 전에 기존 공개 학습 자료가 무엇을 담고 있는지 확인합니다. 모델 크기를 바꾸거나 임계값을 낮춰 앞선 실패를 덮지 않습니다. [표시 기준 검토](../state-hints-claims/PRODUCT-MARKING.ko.md)와 함께, 댓글의 주장과 실제 태스크 상태를 구분합니다.

## 실제 점검 결과

Go 1.27.1 점검 명령을 원본 1,680행·840언어쌍·280관련 그룹에 실행했습니다. 각 언어 840행의 라벨 수는 아래와 같습니다. false는 해당 긍정 주장의 부재이며 미완료 상태를 뜻하지 않습니다.

| 항목 | 한국어 true / false / unknown | 영어 true / false / unknown |
| --- | --- | --- |
| 응답 요청 | 206 / 544 / 90 | 205 / 545 / 90 |
| 진행 보고 | 284 / 499 / 57 | 284 / 499 / 57 |
| 완료 보고 | 318 / 456 / 66 | 316 / 458 / 66 |

진행·완료의 unknown 비율은 각각 약 6.8%·7.9%입니다. 이는 학습 자료의 분포이며 실제 업무 분포는 아직 모릅니다. Unicode 코드 포인트 16개 이하는 0행, 17–32개는 한국어 24행·영어 0행입니다. 바이트 수·코드 포인트 수는 의미 난이도나 모델 토큰 수와 다르며, 이를 근거로 실패 원인을 확정하지 않습니다. Unicode 소문자 변환·공백 정규화 후 정확한 문장 중복과 충돌은 0건입니다. 의미 중복이나 그룹 독립성까지 보장하지는 않습니다. 상세 집계는 [결과](RESULTS.development.json)에 있습니다.

## 참조 판정의 별도 검토

모델 점수나 라벨로 고르지 않고 그룹 ID의 고정 해시 순서로 40그룹·240행을 뽑았습니다. 원래 판정을 숨긴 새 AI 역할이 한국어·영어 문장을 각각 검토하고 전부 봉인한 뒤 원본과 비교했습니다. 720항목 중 716개(99.44%), 세 항목이 모두 같은 행은 236/240(98.33%)였습니다. 2언어쌍·2그룹의 4항목에서 이견이 남았습니다. 원판정과 첫 재판정을 보존했으며 자동으로 라벨을 고치지 않았습니다.

이 수치는 **AI 참조의 일관성**이지 모델 정확도·사람 정답·실사용 합격률이 아닙니다. 같은 문장 틀과 AI 판단의 상관이 남습니다. 전체 1,680행에 대한 의미 검토도 아닙니다. 원래 근거 구간·설명은 비교용 export에 없었고, 목표 값만 비교했다는 한계를 [집계](REFERENCE-CONSISTENCY.development.json)에 남깁니다. 광범위한 라벨 교체를 정당화하는 증거로 쓰지 않습니다.

## 재현과 다음 단계

[점검 명령](../../cmd/riido-statehint-claims-training-audit)은 고정 SHA의 공개 학습 파일만 행 해석 대상으로 허용합니다. stdout에는 집계만 나오고 모델·평가 자료·실제 업무 원문을 사용하지 않습니다. 유지보수 실행 예시는 아래와 같습니다.

```sh
bash scripts/verify-claims-training-audit.sh
```

스크립트는 Hugging Face의 불변 버전에서 자체 공개 학습 파일을 받고 Go 점검 결과를 이 저장소의 고정 집계와 비교합니다. 자동 학습·추론·등록·앱 변경은 없습니다. 실제 점검 1회는 wall 0.61초/CPU user 0.04초/최대 RSS 13,205,504B였으며 읽기·해시·JSON 해석·집계·출력이 포함된 전체 프로세스 관측입니다. 원시 프로파일은 게시하지 않습니다.

다음은 짧고 불명확한 댓글의 자료 범위, 사람에게 유용한 표시 기준과 실제 문맥을 별도로 확인하는 단계입니다. 새로운 자료·가설·평가를 먼저 고정하기 전 추가 Fit을 하지 않습니다. 기존 노출 평가를 학습·선택·개별 오류 튜닝에 재사용하지 않고 보정·최종시험 봉인과 운영 기준을 유지합니다. 이번 신규 Fit은 0회이며 누적 연구 Fit은 23회, 운영 합격 모델은 없습니다. CI 통과는 자료 점검 코드의 재현성을 확인하며 제품 효용을 증명하지 않습니다.
