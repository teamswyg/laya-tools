# 후속 페이지에서 보조 검색 실행 — 실험27

**후속 호출로 페이지 손실을 줄였지만, 기존 합격 기준은 통과하지 못했다.** 고유 질문2,948개 전체에서 주 모델의 페이지는6,326→6,296, 보조 호출은2,408→2,439다. 항상 보조 검색을 쓰는6,287페이지보다9페이지 더 필요하다. 기본 기능은 활성화하지 않는다.

## 사용 관점의 가설

처음 받은20개 후보에서 원하는 것을 찾았다면 보조 검색은 필요하지 않을 수 있다. 못 찾고 다음 페이지를 요청하면 그때 한 번 보조 검색을 실행한다. 처음 보낸 후보는 바꾸지 않고, 남은 후보에 보조 검색 순서를 반영한다. 작은 주장 모델의 최초 판단이 틀리더라도 나중에 도움을 받을 기회를 남기는 방식이다.

이번에는 런타임 세션에 연결하지 않고 이 순서의 효과부터 모의 평가했다. 기존 세션은 순서 해시에 묶인 커서를 사용하므로 중간에 순서를 바꾸려면 별도의 세션 계약과 테스트가 필요하다.

## 고정 조건

[계획](plan-27.json)을 실행 전에 커밋했다. 첫20개 기본 후보를 유지한 뒤, 기존 baseline-first 교차 순서에서 이미 보낸 후보를 제외해 붙인다. 전체 후보3,009개를 보존하며 중복은 없다. 기존16개/20개 특징 모델·임계값·두 초기값과 점수 차이 규칙은 고정했다. 새 학습이나 보정은 하지 않았다. 모델 없는 순수 지연 호출도 별도 비교군이다.

평가기는 알려진 정답이 들어 있는 페이지에서 사용자가 멈춘다고 가정한다. **정답은 평가 중단과 모의 호출 수 계산에만 사용하며 특징·최초 판단·검색 순서의 입력이 아니다.** 실제 사용자는 정답을 알아보지 못하거나 추가 근거를 원할 수 있다. 따라서 이 호출 수는 실제 에이전트 사용량이 아니다. 분석 준비 과정에서는 반사실적 비교를 위해 모든 질문의 보조 순위를 계산했다.

항상 보조 검색은2,948호출/6,287페이지/Recall@10 0.8138이다. 모든 정책의 Recall@1은0.4179다. 후속 호출은20번째 이후에만 순서를 바꾸므로 각 정적 정책의 Recall@10은 그대로다.

주 비교에서는11개 질문에서43페이지를 아꼈지만6개 질문에서13페이지가 늘었다. 순30페이지 절약이다. 20개 특징의 주 초기값에서는6개 질문에서162페이지를 아끼고9개에서17페이지가 늘었다. 큰 손실을 완화하는 효과가 있지만 모든 질문을 개선하지는 않는다. 집계만으로 실험26의 특정 질문과 동일성을 주장하지 않는다.

순수 지연 호출은 항상 보조 검색 대비 모의 호출82.26%를 줄이는 대신164페이지(2.61%)를 더 읽었다. 유용할 가능성이 있는 비용 교환이지만, 원래의 '페이지를 늘리지 않으면서 호출 최소10% 감소' 기준을 완화해 합격으로 바꾸지 않는다. 학습 정책은 고정 점수 차이 규칙보다 페이지·호출이 모두 나쁘지 않고 하나는 더 좋아야 한다는 기존 추가 조건도 유지했다.

## 구현·재현·자원

Go의 `InterleaveAfterPrefix`는 고정 크기 bool 배열과 연속 후보 배열을 사용한다. 입력을 바꾸지 않고 기존 교차 결과를 제자리에서 압축·이동한다. 새 공유 상태나 잠금은 없다. 이 함수는 순서 계산만 하며 보조 검색 자체를 늦추는 실행기는 아니다.

작은 후보집합의 모든 순열·모든 접두부 길이·부분/빈 힌트로 순서·중복·입력 보존을 검증했다. 잘못된 순열, 페이지20/21 경계, 한 번만 호출, 손익 합계도 검사했다. 기존 정적 모델과 규칙의 저장소별·전체 지표가 정확히 재현됐고 전체 새 보고서도 재실행에서 바이트 일치했다. 전체 race/vet와 형식 검사를 통과했다.

M4 Pro CPU에서 다른 테스트 완료 후 재생한 전체 원천 검증·특징 준비·정책 비교·집계는 wall1.44초,user1.46초,peak RSS96,878,592바이트(약92.4MiB)였다. 단일 추론이나 GPU 측정이 아니다. 고정 합성3,009후보/역순 힌트/접두부20의 순서 계산은3회 측정에서7,766–8,005ns,27,648B,2할당이었다. 질의 특징·인덱스 생성·보조 검색·IPC는 제외됐다. CPU 프로파일은 런타임 대기·스케줄링 샘플 비중이 커서 이 결과만으로 검색 병목을 특정하지 않았다. 원본 프로파일은 로컬에만 보관한다.

```sh
go run ./cmd/riido-deferred --out .cache/deferred-helper-new
```

[전체 집계](results-27.json). 새 가중치/HF 배포는 없다. 현재16/20차원 헤드는 자체 선형 모델이며 Laya나3진 모델이 아니다. 이번 결과는3개 저장소의 반복 관찰 개발 자료이며 두 초기값은 독립 데이터가 아니다. 새로운 실제 요청 최소2,400개와 실제 에이전트 완료율·총비용은 미검증이다.

다음은 같은 자료에서9페이지 차이를 줄이는 파라미터 탐색보다, 별도 실제 작업 자료의 라이선스·중복·정답 누출과 평가 가능성을 먼저 점검한다. 공개 이슈 기반 자료가 기존 함수 설명 검색보다 목표에 가까운지 확인하고, 모델 선택·작업 분할의 정답과 혼동하지 않는다.
