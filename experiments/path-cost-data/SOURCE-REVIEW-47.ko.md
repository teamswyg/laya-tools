출처 검토 47의 목적은 원문을 생성하거나 어휘를 학습하는 모델이 아니라, 일반 숫자 특징 16개만 받아 도움 될 힌트를 내는 아주 작은 모델의 로컬 실험 범위를 정하는 것입니다. 기존 정책41과 출처45의 좁은 범위를 유지했습니다. 이 분류는 권리를 보증하거나 공개 모델 배포를 승인하는 판단이 아닙니다.

고정된 학습용 SWE-bench 배포와 공식 프로젝트의 학습 목적·MIT 근거를 확인하고, 당시 저장소 루트에 연결된 실제 라이선스 문서와 별도 구성요소 조건을 검토했습니다. 현재 저장소 라이선스를 과거에 소급하지 않았고, 키워드로 허용 여부를 판단하지 않았습니다. 이슈 작성자 모두의 과거 권리는 여전히 증명되지 않았습니다. 이 미해결 상태는 모든 행을 일괄 승인하거나 일괄 거절하는 근거로 사용하지 않습니다.

새 PyCA 문서는 Apache 또는 BSD 선택과 별도 CPython/PSF 구성요소를 구분했습니다. 한 pip 문서의 CA 인증서 묶음은 LGPL-2.1-or-later 조건을 별도로 남겼습니다. DataDog의 LGPL/AFL 기록을 MIT/BSD 같은 permissive 식별자와 혼동하지 않습니다. pandas에 포함된 Xarray Apache 문서의 차이는 조항 번호 라벨 4개뿐이며 실제 조건은 같습니다. 이런 구분이 작은 숫자 모델의 라이선스를 자동 결정하거나 원문 복제·공개 배포를 승인하지는 않습니다.
