# 개발 정답과 수정 전 파일 목록 연결 — 실험 40

**확보된 파일 목록 1,273개 중 기존 파일 정답이 있는 1,267개를 검사했으며, 정답 경로 4,841개가 모두 해당 시점의 일반 파일과 연결됐다. 전체 13,021개 중 11,748개는 아직 목록이 없어 미검증이다.** 이는 정답과 후보 목록의 연결 검사이며 검색 정확도·학습·모델 품질 검증이 아니다.

[계획](plan-40.json)을 고정한 뒤 실험 38의 첫 재개 실행이 새 요청 2,000회에서 정상 종료될 때까지 기다렸다. 기존 표본/첫 배치 캐시를 포함한 [수집 체크포인트](collection-checkpoint-38.json)는 루트·전체 목록 1,273개, 라이선스 후보 본문이 있는 시점 1,261개다. 후보 본문이 있다는 사실은 라이선스 승인이 아니다. 수집 결과·비공개 객체 목록·실패 목록을 네트워크 없는 재실행으로 재현했다.

연결 검사는 고정된 학습 7,335개·검증 5,686개 전체를 순회한다. 최종 2,402개와 미선택 형제 작업을 제외하고, 실험 39의 고정 원문 투영 해시를 먼저 검증한다. 정답을 얻지 못한 작업이나 목록이 없는 작업을 조용히 제거하지 않는다.

[저장소별 결과](results-40.json). 1,273−1,267=6개는 목록이 있지만 사용할 기존 파일 정답이 없는 사례다. 294개와 58개는 **전체 13,021개 기준**으로, 이 6개나 확보된 1,273개만의 수량이 아니다. 수집 순서는 역할/저장소/ID 순으로 고정했으므로 현재 부분 집합은 무작위 표본이나 전체 성능의 대표 표본이 아니다.

Go는 검증된 정렬 경로 배열을 이진 탐색한다. 일반 파일·실행 파일·심볼릭 링크·하위 모듈·디렉터리·없는 경로를 구분한다. 기존 검색의 파일명 후보 정의에 맞게 일반 파일과 심볼릭 링크의 이름은 후보로 인정하지만, 링크 대상을 읽거나 따라가지 않는다. 하위 모듈과 디렉터리를 일반 파일 정답으로 바꾸지 않는다. 정답 파싱 실패·지원하지 않는 블록·기존 정답 없음은 완전 연결 성공이 될 수 없다.

캐시 판독에 사용하는 콜백은 네트워크를 호출하지 않는다. 캐시가 없을 때만 명시적 미확보로 처리한다. 손상된 압축/JSON·식별자 불일치 등은 실행을 중단하며 미수집으로 덮지 않는다. 기존 루트 2MiB, 저장 카탈로그 32MiB, 100,000항목/16MiB 경로 및 패치 한도를 유지한다. 한 시점의 카탈로그씩 처리하고, 전역 캐시·잠금·동시 캐시 변경을 추가하지 않는다.

비공개 작업별 증거에는 고정 역할·ID·수정 전 커밋, 원 루트 응답 해시, 트리 ID, 정규화된 카탈로그 해시와 경로별 연결 결과를 기록한다. 증거 파일 SHA-256은 `3452e20f925c03a79c5b0527c7decf58efcba00b6bbe78e50fad3e316b32b7c2`다. 공개하는 것은 코드·계획·저장소별 집계와 해시이며 원문·정답 경로·작업별 증거는 게시하지 않는다.

```sh
# 현재 고정 입력과 로컬 캐시에 대한 네트워크 없는 연결 검사
go run ./cmd/riido-developmentjoin --out .cache/development-join-new
```

캐시 수집을 멈춘 동일 시점에서 일반 실행·재실행·전체 race 실행·별도 측정 실행의 집계와 비공개 증거가 모두 바이트 단위로 일치했다. 이후 수집을 재개했으므로 앞으로 같은 명령은 더 많은 목록을 검사할 수 있다. 문서의 1,273개는 해당 완료 체크포인트이며 실시간 상태가 아니다. 합성 검증은 캐시 부재/손상, 다른 커밋의 오용, 경로 종류·정렬·중복, 사용할 수 없는 정답과 전체 분모를 검사한다. 전체 race/vet/형식/redacted scan을 통과한 뒤 공개한다.

수집과 다른 검사가 종료된 뒤 M4 Pro CPU에서 전체 13,021개 입력·1273개 카탈로그 읽기·연결·출력을 한 번 따로 측정했다. wall **2.79초**, user 2.99초, system 0.15초, 최대 RSS **65,699,840바이트(약 62.7MiB)**다. 패치 투영 읽기는 포함하지만 Parquet 변환·네트워크·모델 추론·GPU·학습은 포함하지 않는다. 단일 추론 지연이나 이전 대비 성능 향상 수치가 아니다.

`AllCatalogsAvailable=false`, `AllSupportedTargetsVerified=false`를 유지한다. 다음은 같은 캐시를 사용한 수집 확대와 미검증 사례의 연결 검사다. 과거 라이선스·이슈 이용 조건·학습 승인은 별도로 미완료다. 이 정답은 목표/사후 평가에만 사용하고 추론 입력에는 넣지 않는다. 이번 단계에는 모델 학습·최종 평가·새 Hugging Face 배포가 없다.
