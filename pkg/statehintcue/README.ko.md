# 실험용 질문 문장부호 관측

사람과 에이전트는 `riidolaya question-cue`로 별도 모델 설치 없이 시험할 수 있습니다.

```sh
riidolaya question-cue --role prose --text "캐시를 다시 확인할까요?"
riidolaya question-cue --role metadata --text "요약"
riidolaya question-cue --jsonl < requests.jsonl
```

JSONL의 각 줄은 `{"text":"캐시를 다시 확인할까요?","role":"prose"}`처럼 두 문자열 필드를 갖습니다. 원문은 stdin으로 전달할 수 있고 결과에는 출력하지 않습니다. `cue.question_punctuation=true`는 제한된 문자열 규칙으로 물음표를 관측했다는 뜻입니다. `status=guarded` 또는 `unknown`이면 부분 신호를 사용하지 않습니다. 기존 `state-hint` 모델·규칙·표시 기준은 이 실험과 별개입니다.

JSON escape는 Go 표준 JSON 해석을 따릅니다. 문자열 검사는 해석된 텍스트에 적용하며, 원본 escape 표기의 Unicode scalar 보존을 보장하지 않습니다.

`Inspect(ctx, text, role)`은 호출자가 prose로 지정한 입력의 `?`와 전각 `？`를
관측합니다. 학습 모델, 사전, 확신도, 확률을 사용하지 않습니다. 물음표가 있다는
것은 문법적으로 질문이라는 판단, 필요한 라벨, 권한, 소유자 또는 작업 성공의
증거가 아닙니다. 호출자가 지정한 `prose` / `metadata` / `code` 역할도 입력
분류일 뿐, 소유자가 확인했다는 증거가 아닙니다.

모든 역할에 유효한 UTF-8, NUL 없음, 최대 4096바이트를 적용합니다. 지원하는
역할과 nil이 아닌 context를 명시해야 합니다. metadata와 code는 신호를 내지
않습니다. prose는 물음표를 발견한 뒤에도 끝까지 검사하고 취소를 확인합니다.
잘못된 입력, 취소, 닫히지 않은 코드 구간에서는 부분 신호도 반환하지 않습니다.

의도적으로 작은 문자열 규칙을 적용합니다.

- 연속 백틱이 코드 구간을 열고, 개수가 정확히 같은 백틱만 닫습니다. 인라인
  코드와 fence에 같은 규칙을 사용합니다. 줄 시작, 들여쓰기, 백슬래시 이스케이프는
  해석하지 않으며 코드 안의 다른 길이 백틱은 내용입니다. 전체 Markdown 해석기가
  아니므로 닫히지 않은 구간은 전체 관측을 거절합니다.
- 입력 시작, Unicode 공백 뒤, 여는 괄호·따옴표, `:`·`=` 또는 일치하는 코드
  닫힘 구분자 뒤에 나온
  `http://`, `https://`, `ws://`, `wss://`(ASCII 대소문자 무시)와 `/`를 주소형
  구간의 시작으로 봅니다. 공백 또는 백틱에서 구간이 끝납니다. 붙어 있는 닫는
  괄호나 문장부호는 보수적으로 주소 구간에 포함합니다. 다른 scheme과 임의의
  주소 문법은 해석하지 않습니다.
- 주소형 토큰 끝의 물음표는 전체 문장이 질문일 가능성이 있어도 제외합니다.
  공백 뒤 독립적인 물음표나 그 뒤 일반 단어 끝의 물음표는 관측합니다. 주소 밖에
  물음표가 없는 질문을 문법 추론으로 보충하지 않습니다.

결과는 고정된 출처·guard 값과 bool만 직렬화합니다. 본문, 주소, 해시를 반환하지
않습니다. `ModelUsed`, `ActualVerified`, `StateChangeProposed`,
`MutationExecuted`는 항상 false입니다. 출처 `unlearned_question_punctuation_v1`은
동결된 모델과 기존 발화 규칙과 구별하는 실험 이름이며 기존 동작을 수정하지 않습니다.

테스트와 벤치마크는 직접 만든 공개 문자열 사례만 사용합니다. 검사는 문자열
계약의 검증이며 독립적인 의미 정확도 평가나 운영 지연시간 측정이 아닙니다.
표준 Go만 사용하고 O(n)으로 검사하며 공유 캐시나 잠금이 없습니다. 실제 통합,
소유자 권한과 표시 결정은 이 패키지 밖의 책임입니다.

[개발 비용 기록](COSTS.development.json)은 공개 가상 입력의 반복 검사만 포함합니다. 할당 0회는 전체 프로세스 메모리 0이나 모델·GPU 비용 측정을 뜻하지 않습니다.
