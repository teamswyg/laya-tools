# 고정 Contextual MLP 실험

기존 Contextual2048 특징에 ReLU 은닉16개와 softmax8출력을 연결한 독립
Go 모델입니다. float32 학습 파라미터는32,920개·131,680바이트이며,
별도 `RSM` 버전3 체크섬 모델 파일은131,872바이트입니다.
기존 `statehint`·`statehintwide`, 모델 형식, 실행기나 제품 상태 API를
바꾸지 않습니다.

```go
m := statehintmlp.NewModel() // 새 Glorot-PCG 초기화, 시드1729
report, err := m.Fit(ownedSamples, statehintmlp.FitOptions{
    Epochs: 40, BatchSize: 32, LearningRate: .02,
    WeightDecay: .001, Seed: 1729,
})
if err != nil { /* 학습 오류 처리 */ }
_ = report
var workspace statehintmlp.Workspace
prediction, err := m.Predict("원본의 제한된 입력", &workspace)
_ = prediction
_ = err
```

학습은8범주 교차 엔트로피와 AdamW를 사용합니다. 미니배치 평균 기울기,
두 모멘트의 편향 보정과 가중치 감쇠를 적용하며 bias는 감쇠하지 않습니다.
Glorot uniform 범위는 `sqrt(6/(fanIn+fanOut))`이고 bias 초기값은0입니다.
초기화와 샘플 섞기는 기록된 시드로 만든 별도 PCG 스트림을 사용합니다.
유효한 Fit마다 가중치·최적화기·단계를 새로 시작하고 온도를1로 돌립니다.
이미 학습했거나 읽어 온 모델도 warm start하지 않습니다. 입력 전체를
먼저 검사하고 학습 성공 후에만 모델을 교체하므로, 잘못된 입력이나
수치 실패는 기존 모델을 보존합니다. 초기화 방식과 시드도 기록합니다.

FitOptions의0값은40에포크, 배치32, 학습률.02, 감쇠.001, 시드1729를
뜻합니다. 특히 감쇠0은 기본.001이며 무감쇠 실험을 지정할 수 없습니다.
이는 wide API의 감쇠0 처리와 다르므로 통제 비교에서는 모든 값을
명시해야 합니다. 표본 추출, 보정 학습, 모델 선택, corpus 입출력,
배포나 제품 상태 변경은 구현하지 않습니다.

특징 추출은 같은 Apache-2.0 라이선스의
[기존 contextual 추출기](../statehintwide/features.go)를 독립 복사했습니다.
UTF-8·4096바이트·NUL 제한, Unicode 소문자화, 단어1·2그램,
문자2–5그램, signed FNV-1a 해시, log-TF와 L2 정규화를 유지합니다.
기존 추출기를 공개하거나 수정하지 않고 자체 v2 선형 탐침 모델로
2048개 bin 모두의 비트를 비교합니다. 이는 구현 일치 검증이며 의미
정답이나 일반화의 증명이 아닙니다.

특징에는 텍스트만 사용합니다. Intent·Prediction과8범주 순서는 공통
API를 따릅니다. learned/untrained Source의 기존 wire 태그는
`linear_softmax_*`라는 과거 이름을 유지해 공통 평가기와 호환됩니다.
이는 MLP가 선형이라는 주장이 아니며, 실제 구조는 v3 모델 형식과
이 패키지로 구분합니다. 단어 없는 입력은 균등 확률·unclear 동률과
`no_word_content` guard를 반환합니다.

Predict는 읽기 전용이고 호출자의 Workspace를 재사용하면 할당이
없습니다. 모델을 수정하지 않는 동안만 서로 다른 Workspace로 동시
예측할 수 있으며, Fit·SetTemperature에는 모델의 단독 소유가 필요합니다.
map, 전역 cache, lock, 네이티브·GPU 의존성이나 암묵적 제품 동작이
없습니다.

모델 파일은 구조 차원, ReLU·초기화 코드, 특징 스키마, 의도 순서 해시,
시드·온도·단계 수를 묶습니다. Load는 고정 파일 크기와 뒤의1바이트만
읽어 잘림·추가 데이터·스키마·버전·예약 바이트 변경·손상·비유한 수를
거절합니다. v1/v2/v3는 서로의 모델을 읽지 않으며 체크섬은 손상 탐지이지
출처 인증이 아닙니다. 생성된 모델 바이너리는 소스 저장소에 넣지 않습니다.

테스트는 자체 인공 텍스트·수치 자료로 활성·비활성 ReLU의 수치 미분,
큰 logit의 안정적 손실, bias 없는 감쇠, 작은 실제 학습,
새롭고 결정적인 Fit·실패 시 보존, 동시 예측, 잘못된 모델 파일과
학습 모델의 바이트·예측 복원 일치를 확인합니다. 기존 학습 분할의 한 통제
실행에서 내부 개발 정답은 322/354행이었지만, 완료 정밀도 35/37(94.59%)로
98% 조건을 통과하지 못했습니다. 기존 선형 대조군 선택을 유지했습니다.
이미 관찰한 진단에서는 174/240행이 맞았고 영어 완료 지원은 1/15개여서
두 모델 모두 적격 조건을 통과하지 못했습니다. 보정·최종 시험 호출과 모델
승격은 없었습니다. 이는 개발 관찰이며 새 평가나 의미 일반화의 증거가 아닙니다.
기존 bin의 비선형 조합을 학습할 수 있지만 버린
순서·해시 정보를 복구하거나 테스트만으로 언어 이해를 증명할 수 없습니다.
향후 내부 개발 자료도 이미 노출된 개발 자료이며 외부 검증은 진단만,
최종 test는 봉인 상태를 유지합니다.
