# 고정 Laya 특성의 공유 선형층 시험

여덟 선택지의 고정된 1,024차원 벡터를 받아 공유 float32 가중치 1,024개를
학습하는 원본 Go 연구 패키지입니다. 점수는 `s[i] = dot(w, phi[i])`입니다.
공통 bias는 softmax에서 상쇄되므로 0으로 고정합니다. 분류별 가중치 여덟 벌이나
텍스트 인코더는 들어 있지 않습니다.

`Store`는 변경하지 않는 `io.ReaderAt`을 빌립니다. `ReadRow`는 little-endian
32,768바이트 한 행만 호출자 소유 `Workspace`로 읽습니다. 특성 파일 전체 55MB를
Go 메모리에 올리지 않습니다. 파일 수명과 출처·크기·행 연결·SHA 검사는 호출자
책임이며, 실험 명령이 그 연결을 검사합니다.

`Model.ScoreFeatures(*Row, *Workspace)`는 텍스트가 아닌 특성을 받습니다.
Workspace는 순차 재사용하고, 동시 예측에는 각자의 Workspace와 수정하지 않는
모델을 사용합니다. 학습·온도 변경은 모델을 독점해야 합니다. 새로운 문장은
큰 원본 Laya backbone이 필요하므로, 작은 파일만으로 초저메모리 텍스트 모델이
되는 것은 아닙니다.

`Fit`는 항상 0 가중치와 새 mini-batch AdamW로 시작합니다. CE 기울기는 모든
선택지의 합 `sum_i (p[i]-y[i])*phi[i]`입니다. 기본값은 40 epoch, batch32,
학습률 0.001, 감쇠 0.01, seed1729, temperature1입니다. 입력·수치 실패 시
이전 모델을 보존합니다. 호출자가 준 라벨의 진실성이나 학습 권리를 증명하지 않습니다.

RSP v1은 별도의 **4,320바이트 특성용 형식**입니다. 가중치 4,096바이트,
헤더 192바이트와 손상 검사 32바이트로 구성합니다. 특성 형식·여덟 의도 순서·
원본 모델과 질문 계약, 온도·seed·이 Go 선형층의 실제 업데이트 수를 기록합니다.
backbone의 알 수 없는 학습 이력을 만들지 않습니다. 기존 v1/v2 텍스트 `.rsh`나
v3 MLP `.rsm` 로더로 읽지 못합니다. 이 패키지의 `Save`·`Load`를 사용하며,
체크섬은 발행자 인증이 아닙니다.

작은 원본 행렬로 유한 차분 기울기·AdamW 첫 업데이트·행 단위 읽기와 경계,
작은 실제 학습·실패 시 보존·새 학습 시작·파일과 예측 복원 일치를 검사합니다.
코드와 수치 검증이며 실제 Laya 추론이나 의미 분류 성능의 근거는 아닙니다.

첫 실제 고정 실험은 학습1,326행·업데이트1,680회를 완료했지만 표시 근거 목표에
실패했습니다. 이미 관찰한 내부 개발118/354·검증92/240 정답이었고, **두 언어 모두
진행·완료·질문 표시 후보가0건**이었습니다. 정밀도는 정의되지 않으며 완벽한 결과가
아닙니다.4,320바이트 학습 파일의 복원 일치는 확인했지만 의미 분류 적격은 아닙니다.
수치와 자원 구분은 명령의 [실제 결과](../../cmd/riido-statehint-shared-probe/README.ko.md)를
참고하세요. 선택·보정·최종 시험·승격은 하지 않았고, 새 문장은 여전히 큰 backbone이
필요합니다.
