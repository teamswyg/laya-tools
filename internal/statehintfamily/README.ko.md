# 가족 단위의 캐시 점수 평가

`Evaluate(corpus, predictions)`는 원본 행 순서로 이미 계산된 점수를 받아 한 사건의
한국어·영어 쌍을 평가합니다. 모델을 생성·학습·예측하거나 자료를 변경하지 않습니다.
원문·ID·계보 이름은 결과에 넣지 않습니다. 선언된 점수 출처와 계보를 검사해도
실제 모델 provenance, 의미 정답, 권리나 통계적 독립성을 증명하지는 않습니다.

의도 배열은 기존 8개 열 순서입니다. 표시 배열은 진행/완료 보고/질문/없음이며,
언어 배열은 ko/en입니다. 실제 표시 기준은 **8개 열의 원래 승자**에 learned 출처,
양수 학습 step, guard 없음, confidence .9 이상, margin .05 이상을 적용합니다.
없음의 확률은 다른 다섯 열의 합이며 기권 비트가 아닙니다. 그 합의 argmax로
실제 승자를 교체하지 않습니다. NLL은 1e-15로 잘린 경우를 따로 세고,
Brier는 제곱 차의 합입니다. 두 행의 평균을 낸 뒤 가족 사이에서 평균합니다.

가족 안에서 한 언어라도 잘못 제안한 완료/질문/진행에는 10/3/1의 비용을 적용하고,
놓친 대상 표시의 두 행 평균을 더합니다. 자격에는 각 표시·언어별 올바른 표시율
.2 이상, 올바른 가족 5개 이상, 올바른 **선언 계보** 2개 이상이 필요합니다.
완료 제안 분모는 0이 아니고 정밀도 .98 이상, 비용은 .375 미만이어야 합니다.
클래스당 언어별 15행에서는 가족 5개가 33.3%를 뜻합니다. 전체 분할 수와 원본
계보·의미·권리 검토는 실행기가 확인해야 합니다. `Eligible`은 운영 승인이나
테스트 정답 보장이 아닙니다.

untrained와 rule 점수도 raw 혼동행렬·손실을 기술할 수 있지만 learned 표시 기준을
통과하지 않습니다. 규칙의 one-hot 점수는 보정된 확률이 아닙니다. 보고서는 보정
성공을 주장하지 않으며, 해당 control의 전체 보류 비용은 모델 유용성 증거가 아닙니다.
원본 수작업 산술 fixture로 계산을 검사하며 학습 모델이나 실제 업무 정확도 검사는 없습니다.
