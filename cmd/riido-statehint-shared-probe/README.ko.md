# 고정 특성에서 Go 선형층을 한 번 학습하기

고정된 Laya 표현과 원래 AI가 작성·검토한 라벨로 V4 범위를 학습할 수 있는지
확인하는 관리자용 실험입니다. 교사 예측을 정답으로 쓰거나 backbone을 실행하거나
여러 설정을 탐색하지 않습니다. 특성 추출이 완전히 끝나고 해시가 고정돼야 학습합니다.

train840의 한·영 1,680행을 고정 계보 분할로 나눕니다. 학습 가족663개(1,326행),
이미 관찰한 내부 개발177개(354행)입니다. 공유 가중치1,024개를 0에서 시작해
40 epoch, batch32, 학습률0.001, AdamW 감쇠0.01, seed1729, temperature1,
업데이트1,680회로 한 번만 학습합니다. 공통 bias는0입니다. 기존240행 검증
특성 캐시를 그대로 사용하며 다시 추출하지 않습니다.

## 입력과 사용법

저장소 루트에서 Go1.27.1을 사용합니다. `train`, `split`, `features`, `sidecar`,
`validation`, `validation-features`, `validation-scores`, `reference-report`에
각각 로컬 상대 경로와 SHA를 직접 지정합니다.

```sh
go run ./cmd/riido-statehint-shared-probe \
  --train train840.jsonl --train-sha256 TRAIN_SHA \
  --split frozen-split.json --split-sha256 SPLIT_SHA \
  --features features.f32le --features-sha256 FEATURE_SHA \
  --sidecar sidecar.json --sidecar-sha256 SIDECAR_SHA \
  --validation exposed-validation120.jsonl --validation-sha256 VALIDATION_SHA \
  --validation-features validation-features.f32le --validation-features-sha256 VALIDATION_FEATURE_SHA \
  --validation-scores scores.json --validation-scores-sha256 SCORES_SHA \
  --reference-report reference-report.json --reference-report-sha256 REFERENCE_SHA \
  --check
```

`--check`는 전체 출처·분할·특성 해시와 행 연결을 확인하며 학습·native 호출·
출력 파일 생성은 하지 않습니다. 실제 한 번의 학습은
`--fit --out .cache/statehint-shared-probe/NEW-RUN`으로 바꿉니다. 원본 자료·분할·
검증 자료·검증 특성의 해시는 고정입니다. 새 학습 특성·연결 파일 해시는 승인된
추출이 성공한 후에 받습니다. 학습 설정 변경·보정·최종 시험·새 추출·다운로드
옵션은 없습니다.

연결 형식은 `riido-statehint-laya-feature-sidecar-v1`입니다. 원본 모델·질문,
여덟 의도 순서, 원문·특성 해시, 정확한 `[1680,8,1024]` 형태, little-endian
float32와 특성 행 순서를 연결합니다. 각 행의 ID·언어·문장 해시·원래
`expected_intent`를 Go 원본 라벨과 대조합니다. 라벨은 backbone 입력이 아닙니다.
기존 본문 없는 검증 점수 파일은 그 특성 캐시의 행 순서를 연결합니다.

전체 해시는 스트리밍하고, 학습 때는32KiB 한 행씩 읽습니다. 학습55,050,240바이트와
검증7,864,320바이트 파일을 Go 배열로 또 복사하지 않습니다. 별도 MPS 추출 작업자가
끝나 backbone을 해제한 뒤 순수 Go 선형층을 학습합니다.

## 출력과 해석

0700 새 폴더에0600 레시피·원본 행 위치와 라벨·실제 학습 파일·여덟 확률·집계를
덮어쓰기 없이 저장합니다. 원문과 큰 특성 파일은 복제하지 않습니다.4,320바이트
RSP 파일은 `pkg/statehintsharedprobe.Load`로 읽고 같은 고정 특성의
`ScoreFeatures`로 예측합니다. 텍스트 `.rsh`/`.rsm` 로더와 호환되지 않으며,
새 문장은 큰 backbone 없이는 처리할 수 없습니다.

기존 원본·교체 파일의 검증 집계를 같은 캐시의 참고 비교로 남깁니다. 그 모델의
알 수 없는 과거 학습을 Go 업데이트로 바꾸지 않습니다. 새 선형층의1,680회만
실제로 압니다. 기존 가족 평가기의 적합 판정은 설명용이며 배포 적격이 아닙니다.
두 평가 자료 모두 이미 관찰했고 선택 가중치는0이며 모델 선택·승격은 없습니다.
신뢰도0.9·마진0.05를 유지합니다. AI 라벨은 사람 정답이 아니며 완료 보고로
실제 업무 상태를 바꾸지 않습니다.

임시 원본 특성·자료로 라벨과 순서, 학습·개발 격리, 기울기·수치·파일 경계와
학습 파일 복원 일치를 확인합니다. 첫 실제 실행의 실패 결과는 아래에 기록했습니다.

## 첫 실제 실행: 표시 근거 목표 실패

정밀도는 정의되지 않고 올바른 표시 범위도0입니다. 잘못된 후보0건은 전부
판단을 유보했기 때문이며, 유용한 안전성이나 인식 성공의 근거가 아닙니다.
