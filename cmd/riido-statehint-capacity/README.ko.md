# 같은 자료로 선형 모델과 작은 MLP 비교하기

작은 비선형 모델이 여덟 가지 상태 힌트 분류에 도움이 되는지 확인하는
관리자용 실험 명령입니다. 두 모델은 **같은 순서의 학습 문장 1,454개**와
같은 Contextual2048 특성을 받습니다. 기존 선형 softmax 모델은 가중치 0에서
시작하고, 작은 MLP는 Glorot 초기화와 ReLU 은닉 유닛 16개를 사용합니다.
따라서 **초기화를 포함한 구조 묶음**의 비교입니다. 활성화 함수 하나의 효과,
어순만의 효과, Laya 파인튜닝, 3진 모델 또는 제품 개선을 증명하는 실험은 아닙니다.

원래 고정한 train840 자료를 기존 계보 단위 분할로 나눠 663개 가족만 학습하고,
177개 가족은 내부 개발 비교에 사용합니다. 기존 대조군과 똑같이 seed1729의
SHA 순위로 학습 쪽에서 KO/EN 가족 64개를 통째로 다시 뽑습니다. 완료 32개와
막힘·참고·진행·계획 각 8개입니다. 의미 대조 증강 자료나 이전 학습 모델은
받지 않습니다. 내부 개발 자료 177개는 이미 관찰했으므로, 새로운 독립 검증이나
사람이 확정한 정답 세트로 취급하지 않습니다.

## 실행 방법

저장소 루트에서 Go **1.27.1**을 사용합니다. 승인된 로컬 자료와 고정 분할을
직접 지정해야 합니다. 원문 개발·진단 자료는 공개 저장소에 포함되지 않습니다.
아래 파일 이름을 저장소 안의 상대 경로로 바꿔 사용하세요. 두 입력 해시는
고정되어 있으며, 다른 자료를 시험하기 위한 설정값이 아닙니다.

```sh
go run ./cmd/riido-statehint-capacity \
  --train train840.jsonl \
  --train-sha256 586f1862241bf0e43734494911d503b6aaedac979215f9fdd802f43e5c7a660e \
  --split frozen-split.json \
  --split-sha256 f5f661243684b0b65e171dbbc78c024c31264dc1c00481e1ba04926da39dede9 \
  --check
```

`--check`는 자료·분할·추출을 검사합니다. 모델 호출과 출력 폴더 생성은 하지
않습니다. 실제 비교는 이를 `--fit --out .cache/statehint-capacity/NEW-RUN`으로
바꿉니다. 새 출력 폴더만 사용할 수 있어 이전 기록을 보존합니다. 두 모델 모두
40 epoch, batch32, 학습률 0.02, AdamW 감쇠 0.001, seed1729, temperature1,
**업데이트 1,840회**로 고정합니다. 학습 설정을 바꾸는 옵션은 없습니다.

선택 옵션 `--validation exposed-validation120.jsonl --validation-sha256 SHA`는
이미 관찰한 균형 진단 자료를 각 학습 후에 평가합니다. 이 자료의 라벨·점수는
학습, 재조정, 보정, 모델 선택에 사용하지 않습니다. calibration, 최종 test,
증강 자료, 부모 모델 입력은 지원하지 않습니다.

기존 가족 단위 평가와 **신뢰도 0.9 / 마진 0.05** 기준을 유지합니다. 내부 개발
결과 중 기준에 적합한 모델만 오류 비용, 여덟 분류 NLL, 고정 순서
(선형 먼저, MLP 다음)로 비교합니다. 선택은 연구 결과이며, 적합 판정을 받아도
배포·승격하거나 새로운 일반화 성능을 확정하지 않습니다. 실패하면 부분 출력과
`FAILED.json`을 남깁니다.

## 출력과 모델 읽기

0700 비공개 폴더에 0600 파일을 덮어쓰기 없이 저장합니다. 입력 원문과 해시,
가족 단위 추출 내역, 학습 순서별 라벨·문장 해시, 평가 원본 행 순서의 여덟 확률,
집계 보고서, 실제 학습한 모델이 포함됩니다. 원문과 평가 메타데이터가 있으므로
전체 실행 폴더는 로컬에 보관하세요. 공개 집계·모델은 별도 검토 후 게시합니다.

| 모델 | 파일 형식 | 크기 | Go 로더 |
| --- | --- | ---: | --- |
| Contextual 선형 모델 | RSH v2, `.rsh` | 65,728바이트 | `pkg/statehintwide.Load(io.Reader)` |
| ReLU 은닉 유닛 16개 MLP | RSM v3, `.rsm` | 131,872바이트 | `pkg/statehintmlp.Load(io.Reader)` |

예측 결과는 둘 다 같은 `statehint.Prediction` 타입입니다. 예측에는 해당 패키지의
호출자가 소유하는 `Workspace`를 사용하며, 두 Workspace 타입은 서로 다릅니다.
MLP는 float32 매개변수 32,920개를 사용합니다. v3 모델은 **기존 v1 CLI/SDK와
v2 선형 로더로 읽을 수 없습니다**. 이 명령은 실제 저장 파일을 해시로 확인한 후
맞는 로더로 읽고, 저장 전후 모든 예측의 완전 일치와 재저장 바이트의 일치를
확인합니다. SHA-256은 손상 검사용이며 모델 발행자 인증 수단은 아닙니다.

학습·예측 경과 시간과 학습 직후 Go heap을 기록합니다. Go heap은 전체 메모리나
운영체제 최대 RSS가 아닙니다. 전체 실행의 최대 RSS는 외부에서 측정하세요.
macOS에서는 한 번 빌드한 실행 파일을 `/usr/bin/time -l`로 실행할 수 있습니다.
GPU를 사용하지 않는 순수 Go CPU 실행입니다. 순차 실행 시간과 한 번의 측정만으로
안정적인 성능 벤치마크를 확정하지 않습니다.

임시 합성 자료 테스트는 분할·추출의 분류 비율, 개발·진단 라벨의 학습 격리,
두 실제 학습 파일의 저장·복원 일치, 공통 예측·평가 타입, 입력 크기와 비공개
새 출력 폴더를 확인합니다. 작은 테스트 학습은 코드 동작을 검증하며 의미 분류
성능의 근거는 아닙니다.

## 관측된 개발 실행

같은 순서의 1,454행으로 후보당 1,840업데이트를 실제 수행했습니다.
선형 모델은 이전 대조군과 정확히 같은 SHA-256을 재현했습니다. 내부 개발
자료는 이미 결과가 노출됐으므로 이 비교는 새로운 적격 평가가 아닙니다.

| 모델 | 내부 분류 정답 | 내부 표시 정답/제안 | 내부 완료 정밀도 | 내부 기준 | 진단 정답 | 진단 표시 정답/제안 | 진단 완료 KO/EN |
|---|---:|---:|---:|---|---:|---:|---:|
| 선형 | 317/354 | 73/74 | 26/26 | 통과·연구 선택 | 172/240 | 39/39 | 4/15·0/15 |
| MLP16 | 322/354 | 91/95 | 35/37 (94.59%) | 미달 | 174/240 | 52/55 | 5/15·1/15 |

MLP는 내부 완료 오제안이 두 가족·두 계보(언어별 한 건) 생겨 98% 정밀도
기준을 실패했습니다. 내부 NLL은 낮아졌으므로 전체 과신을 증명한 결과는
아닙니다. 진단은 두 모델 모두 영어 완료 지원 부족으로 자격 미달입니다.
진단 결과로 내부 선택을 바꾸지 않았습니다.

모델 저장·재읽기의 모든 예측 필드와 재직렬화 바이트가 정확히 일치했습니다.
두 군 전체 실행은 1.95초(user CPU 1.87초), 프로세스 최대 RSS
24,887,296바이트(~23.73MiB)였습니다. 한 번의 전체 실행 관측이며 이전
실험과의 RSS 차이를 메모리 개선으로 해석하지 않습니다. GPU·보정·최종
시험·운영 승격은 0회입니다. 기존 결과와 가중치는 그대로 보존합니다.
