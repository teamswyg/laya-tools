# 완료 대조의 통제 비교

관리자용 Go 명령으로 기존 `statehintwide.Contextual2048`을 새로 초기화한
두 학습군을 비교합니다. 고정 train840 분할의663개 학습 가족과177개 내부
개발 가족을 사용합니다. 두 학습군은 각각1,454행과1,840업데이트입니다.

- `class_matched_control`:663개 학습 가족에 같은 학습 집합에서 뽑은
  64개 **KO/EN 전체 가족 표본**을 추가합니다. 완료32, 참조8, 진행8,
  계획8, 장애8입니다. `completion-contrast-class-matched-control-1729:`와
  가족 ID를 이어 붙인 SHA-256 순서로 뽑으며 동률은 가족 ID 순입니다.
  해당 범주의 후보가 부족할 때만 같은 순서를 순환합니다. 중복 추출은
  표본 가중치이며 새 가족이나 독립 사례가 아닙니다.
- `matched_semantic_contrast`: 같은663개 가족에 실제 원본 학습 소스에서
  파생한64개 증강 가족을 추가합니다. 범주별·언어별 행 수는 대조군과 같습니다.

두 군 모두 기존 가중치 없이 새로 시작합니다.40에포크, 배치32,
학습률.02, AdamW 감쇠.001, 시드1729, 온도1을 고정합니다.
모델 특징에는 텍스트만, 학습 목표에는 학습 쪽 예상 의도만 사용합니다.
단위·계보 등 주석은 특징이 아닙니다.

```sh
go run ./cmd/riido-statehint-contrast \
  --train train840.jsonl --train-sha256 TRAIN_SHA256 \
  --augmentation augmentation64.jsonl --augmentation-sha256 AUGMENTATION_SHA256 \
  --split split.json --split-sha256 SPLIT_SHA256 \
  --source-overlay source-groups.json --source-overlay-sha256 AUDIT_SHA256 \
  --check
```

원본 학습·분할 해시는 명령에 고정된 연구 해시와 같아야 합니다.
증강·소스 감사 파일도 명시적인 소문자 SHA-256 핀이 필요합니다.
`--check`는 입력 검증만 하며 출력 파일이나 모델 호출이 없습니다.
실제 입력의 학습 실행이 허가된 후
`--fit --out .cache/statehint-completion-contrast/NEW-RUN`으로 비교합니다.
두 모드 중 하나만 지정해야 합니다. 기본 입력, 학습 설정 변경, calibration,
최종 test, 전체 manifest, 기존 모델 입력은 없습니다.

선택적 `--validation validation120.jsonl --validation-sha256 SHA`는 이미
결과가 노출된 개발 검증 자료입니다. 두 군 모두 같은 진단을 수행하지만 선택
가중치와 모델 승격은 항상0입니다.

필수 소스 감사의 스키마는
`statehint-completion-contrast-source-groups-v1`입니다. 상위 필드는
`augmentation_sha256`, `train840_sha256`, `frozen_internal_split_sha256`,
64개 `entries`입니다. 각 항목은 가족·짝 ID, 예상 의도, 실제 계보 그룹,
연결된 소스 가족·그룹, 그 그룹의 원본 선택 구성원 전체와 KO/EN 순서의
행 ID·텍스트 해시를 묶습니다. 정확한 필드 이름은 영문 문서에 있습니다.
추가 출처 정보도 감사 원본에 보존합니다. 연결된 원본 구성원은 모두 고정
학습 쪽이어야 하며, 같은 소스에 연결된 증강 가족은 같은 그룹이어야 합니다.
짝은 완료 가족 하나와 참조·진행·계획·장애 중 하나로 구성합니다.
원본840 그룹이나 내부 개발 분할을 변경하지 않습니다.

선택은177개 내부 개발 가족에서만 수행합니다. 기존
`statehintfamily.Evaluate`의 신뢰도.9, 마진.05, 정답 커버리지.2,
언어·P/C/Q별 정답 가족5개·계보2개, 완료 정밀도.98,
심각도 비용.375 미만 조건을 유지합니다. 조건을 통과한 군 사이에서
심각도 비용,8의도 NLL, 고정 군 순서로 선택합니다. 둘 다 실패하면
선택하지 않고 이전 부모 모델을 유지합니다. 명령은 운영 모델을 승격하거나
배포 적격성을 주장하지 않습니다.

새 실행 디렉터리는0700, 모든 출력 파일은0600이며 기존 파일을 덮어쓰지
않습니다. 정확한 입력·분할·감사 원본, 고정 레시피, 대조군 전체 가족
추출 기록, 두65,728바이트 모델,8확률 벡터, 내부 개발·선택적 진단 보고서와
핀을 저장합니다. 저장 모델을 다시 읽어 직렬화 바이트와 모든 평가 행의
예측이 정확히 같은지 검사합니다. 잘못된 입력에는 출력이 없고, 학습·출력
실패에는 `FAILED.json`과 실패로 표시된 부분 산출물을 남깁니다.

학습·예측 시간과 학습 후 Go 힙을 따로 기록합니다. Go 힙은 OS RSS가
아니므로 실제 실행 시 호스트 도구로 프로세스 최대 RSS도 측정해야 합니다.
네이티브·GPU 런타임을 사용하지 않으며 실행 전 정확도·속도 향상을
주장하지 않습니다.

증강은 기존 평가 작성 문맥에 노출된 AI의 소스 파생 TRAINONLY 감독
데이터입니다. 해시·구조 검증은 의미 라벨, 인간 정답, 독립 사건, 짝 설계만의
인과 효과나 새로운 평가를 증명하지 않습니다. 테스트의 자체 인공 자료와
작은 실제 학습은 분리·표본 추출·입출력·저장 복원의 정확성만 확인합니다.

## 실제 통제 개발 실행

고정663/177 내부 분할과 승인된64가족·128행 TRAINONLY 증강으로
실행했습니다. 두 군 모두1,454행·1,840업데이트를 학습했고 저장 후
복원 예측·바이트 일치를 통과했습니다.

| 학습군 | 내부 개발8의도 정답 | 게이트 정답 / 제안 | 완료 정밀도 | 심각도 비용 | 적격 |
|---|---:|---:|---:|---:|---|
| 범주를 맞춘 대조군 | 317/354 | 73/74 | 1.00 | 0.138418 | 통과·선택 |
| 의미 대조 증강군 | 317/354 | 72/73 | 0.96 | 0.192090 | 완료 정밀도 실패 |

고정 내부 개발 규칙이 대조군을 선택했습니다. 증강군의 완료 정밀도는
기존0.98 조건에 못 미쳤습니다. 이미 결과가 노출된 개발 검증 자료의
진단 결과로 이 선택을 바꾸지 않습니다.

| 학습군 | 진단8의도 정답 | 게이트 정답 / 제안 | KO / EN 완료 정답 가족 | 진단 적격 |
|---|---:|---:|---:|---|
| 범주를 맞춘 대조군 | 172/240 | 39/39 | 4/15 · 0/15 | 실패 |
| 의미 대조 증강군 | 183/240 | 48/48 | 7/15 · 2/15 | 실패 |

두 군 모두 영어 완료 지원 등이 부족해 진단 조건을 통과하지 못했습니다.
증강군의 높은 진단 수치는 기술적 관찰이며 인과 효과나 새로운 평가의
향상을 증명하지 않습니다. calibration·최종 test 호출과 모델 승격은
없었습니다. 모델은 각각65,728바이트였고, 이 한 실행에서 총1.86초와
프로세스 최대 RSS26,165,248바이트를 관측했습니다. 다른 호스트의 자원
보장은 아니며, 소스 파생 감독과 상관된 AI 라벨의 한계는 그대로입니다.
