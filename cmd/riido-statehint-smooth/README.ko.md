# 고정된 MLP 라벨 스무딩 비교

같은 Go MLP(Contextual2048 → ReLU 유닛 16개 → softmax 8개)를 새로 학습하는
관리자용 비교 명령입니다. 미리 정한 차이는 학습 정답의 분포뿐입니다.
일반적인 정답 라벨 cross entropy(**α=0**)와 균일 라벨 스무딩(**α=0.05**)을
비교합니다.

`q[c] = (1 − α) × one_hot[c] + α/8`, cross entropy의 기울기는 `p − q`입니다.

α=0.05에서는 정답 분류에 0.95625, 다른 분류 각각에 0.00625를 줍니다.
알려진 정규화 방식이며, 지나치게 확신한 일부 오류를 줄일 가능성이 있습니다.
동시에 올바른 판단도 표시 기준을 넘지 못할 수 있습니다. 개선 여부나 이전
완료 오류의 원인은 미리 확정하지 않습니다. 분리된 개발 실험이며, Laya
파인튜닝·3진 학습·검증된 제품 업데이트가 아닙니다.

두 모델 모두 기존 대조군의 준비 과정을 그대로 사용합니다. 원래 고정한
train840 자료에서 **계보 단위 학습 가족 663개**와 동일한 KO/EN 가족 추출
64개를 사용해 **같은 순서의 학습 문장 1,454개**를 받습니다. 완료 32개와
막힘·참고·진행·계획 각 8개를 학습 쪽에서 통째로 다시 뽑습니다. 내부 개발
177개 가족은 이미 관찰했으므로 새로운 독립 검증이나 사람이 확정한 정답으로
취급하지 않습니다. 의미 대조 증강이나 이전 학습한 부모 모델은 읽지 않습니다.

## 실행 방법

저장소 루트에서 Go **1.27.1**을 사용하고, 승인된 로컬 원본 자료와 고정 분할을
저장소 안의 상대 경로로 지정합니다.

```sh
go run ./cmd/riido-statehint-smooth \
  --train train840.jsonl \
  --train-sha256 586f1862241bf0e43734494911d503b6aaedac979215f9fdd802f43e5c7a660e \
  --split frozen-split.json \
  --split-sha256 f5f661243684b0b65e171dbbc78c024c31264dc1c00481e1ba04926da39dede9 \
  --check
```

`--check`는 입력·분할·추출을 검사하며 학습, 모델 호출, 출력 파일 생성을 하지
않습니다. 실제 비교는 `--fit --out .cache/statehint-label-smoothing/NEW-RUN`으로
바꿉니다. 새 폴더만 사용할 수 있습니다. 두 모델 모두 40 epoch, batch32,
학습률 0.02, AdamW 감쇠 0.001, seed1729, temperature1, **업데이트 1,840회**로
고정합니다. 구조·초기화·섞기 방식은 같으며 α 탐색이나 학습 설정 변경 옵션은
없습니다.

α=0 모델은 이전 실제 MLP 파일의 SHA-256을 완전히 재현해야 합니다.

`43d41cb923b33bbbd96879488376ad5c3f600bdd53860d6d6fba852751c0c0b4`

일치하지 않으면 부분 실패 기록을 보존하고 **α=0.05 학습 전에 중단**합니다.
결과를 만들기 위해 이 해시를 바꾸거나 우회하지 않습니다.

선택 옵션 `--validation exposed-validation120.jsonl --validation-sha256 SHA`는
이미 관찰한 균형 진단 자료를 각 고정 학습 후 평가합니다. 라벨·점수는 학습,
보정, 선택에 사용하지 않습니다. calibration, 최종 test, 증강 자료, 부모 모델,
α 변경 입력은 지원하지 않습니다. 기존 가족 단위 평가와 **신뢰도 0.9 / 마진
0.05** 기준을 유지합니다. 연구용 선택은 내부 개발 결과 중 적합한 모델의
오류 비용, 여덟 분류 NLL, 고정 순서(α=0 먼저)를 사용합니다. 배포·승격이나
새로운 일반화 성능을 확정하지 않습니다.

## 기록과 모델 읽기

0700 비공개 실행 폴더에 0600 파일을 덮어쓰기 없이 저장합니다. 입력 원본,
가족 추출, 학습 순서별 라벨·문장 해시, 평가 원본 행 순서의 여덟 확률,
집계 보고서, 실제 학습 모델 두 개와 저장·복원 일치 근거를 남깁니다. 원문과
평가 기록은 로컬에 보관하며 공개 집계·모델은 별도로 검토한 뒤 게시합니다.

두 모델은 모두 **RSM v3**, 131,872바이트이고 float32 매개변수 32,920개를
사용합니다. `pkg/statehintmlp.Load(io.Reader)`로 읽고 해당 패키지의 호출자가
소유하는 `Workspace`로 예측합니다. 결과 타입은 공통 `statehint.Prediction`입니다.
기존 v1 CLI/SDK와 v2 선형 로더로는 읽을 수 없습니다. 모델 파일에는 추론
가중치를 저장하며, 레시피와 각 학습 보고서에 라벨 스무딩 값을 기록합니다.
저장 파일 해시, 저장 전후 모든 예측, 재저장 바이트의 완전 일치를 검사합니다.
체크섬은 손상 검사용이며 발행자 인증 수단이 아닙니다.

학습·예측 경과 시간과 학습 직후 Go heap을 기록합니다. Go heap은 운영체제
최대 RSS가 아닙니다. 전체 프로세스 최대 RSS는 외부에서 측정하세요. macOS는
미리 빌드한 실행 파일에 `/usr/bin/time -l`을 사용할 수 있습니다. GPU를 쓰지 않는
순수 Go CPU 실행입니다. 순차 실행 한 번으로 안정적인 벤치마크를 확정하지 않습니다.

임시 합성 자료 테스트로 기존 대조군 준비의 일치, 직접 패키지 학습과 목적 함수
연결, 기본 α=0 동작, 실제 다른 학습 파일에 대한 기준 해시 불일치 중단,
개발·진단 라벨의 학습 격리, 두 학습 모델의 저장·복원 일치를 확인합니다.
작은 테스트 학습은 코드 동작을 검증하며 의미 분류 성능의 근거는 아닙니다.

## 첫 실제 개발 실행 결과

두 모델 모두 실제 고정 학습을 완료했습니다. α=0 파일은 요구한 이전
SHA-256을 완전히 재현했고, 두 131,872바이트 v3 파일 모두 예측과 재저장
바이트의 완전 일치를 확인했습니다. 각각 같은 학습 행 1,454개와 업데이트
1,840회를 사용했습니다. 보정·최종 test·승격은 하지 않았습니다.

| 측정 항목 | 일반 CE, α=0 | 스무딩, α=0.05 |
| --- | ---: | ---: |
| 이미 관찰한 내부 개발: 여덟 분류 정답 | 322/354 | 305/354 |
| 내부 개발: 올바른 표시 / 전체 표시 | 91/95 | 39/39 |
| 내부 개발: 올바른 완료 / 전체 완료 표시 | 35/37 | 14/14 |
| 내부 개발 기준 적합 여부 | 부적합 | 적합; 연구용 선택만 |
| 이미 관찰한 진단: 여덟 분류 정답 | 174/240 | 158/240 |
| 진단: 올바른 표시 / 전체 표시 | 52/55 | 11/11 |
| 진단: 올바른 완료 가족, KO / EN | 5 / 1 | 0 / 0 |
| 진단 기준 적합 여부 | 부적합 | 부적합 |

스무딩은 두 평가 자료에서 표시 오류가 없었고, 내부 개발의 올바른 완료
근거는 KO5 / EN9 가족이었습니다. 기존 모델의 내부 잘못된 완료 가족 2개를
줄이는 대신 표시 범위를 줄였습니다. 진단에서는 **완료 표시 자체가 0건**이므로
완료 정밀도는 **정의되지 않습니다**. 정밀도 0이나 완벽한 성공률로 해석하면
안 됩니다. 유용한 진단 성능 개선이나 새로운 배포 근거는 확인하지 못했습니다.
연구용 선택은 내부 개발 결과만으로 α=0.05를 골랐고, 진단은 선택에 사용하지
않았습니다.

일반 CE와 스무딩 CE는 정답 분포가 달라 평균 학습 손실을 직접 비교할 수
없습니다. 두 모델의 전체 순차 실행은 약 2.20초였고, 외부에서 측정한 프로세스
최대 RSS는 27,197,440바이트였습니다. 모델별 측정이나 GPU 측정값이 아닙니다.
